# 常见问题

**免费吗？** 是。本项目提供完整开源安装版，无解锁购买环节。AI 工具本身或外部服务可能有自己的费用。

**给 AI 一个地址就行吗？** 对支持联网读取仓库、本地文件操作和 Skill 安装的工具，可以让它按首页委托完成安装。普通聊天未必有这些能力，请按安装指南下载或上传材料。

**需要全部安装吗？** 不需要。可以只安装当前任务需要的一项；Google Ads 与 Google SEO 是两项独立 Skill。

**安装后会自动投广告、发帖或改店铺吗？** 不会。当前主要完成离线准备与交接，真实外部操作需要另行授权和适用工具。

**能生成视频吗？** 广告素材 Skill 提供文字创意、脚本、分镜和制作简报；成片另需制作工具。

**能生成 Excel 吗？** 数据 Skill 提供五表核算流程和程序，但自动工作簿输出需要兼容的 Codex 运行时。普通聊天可读方法，不应冒称已运行。

**可以修改或参与完善吗？** 可以，按 MIT 与第三方相应许可，Fork 后提交 PR。先阅读[贡献指南](../CONTRIBUTING.md)。

**如何更新？** 见[更新说明](updates-and-feedback.md)，保留旧版本和个人修改，不直接覆盖。
