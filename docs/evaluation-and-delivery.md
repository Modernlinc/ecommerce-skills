# 获取完整包

本仓库直接提供完整开源安装版，无购买、解锁或单独付费交付步骤。

- 浏览：在 [18 项目录](skill-catalog.md) 选择任务。
- 下载：仓库 Code → Download ZIP，或 git clone。
- 安装：[安装指南](getting-started.md)，可全装或只装一项。
- 练习：从每项 examples/input.md 开始，再对照参考输出。
- 贡献：[提交问题或改进](../CONTRIBUTING.md)。

许可见 [MIT](../LICENSE)，实际运行要求见 [兼容说明](compatibility.md)。AI 工具自己的订阅、模型额度或外部服务费用由相应工具决定，本项目不收费也不代付这些服务。
