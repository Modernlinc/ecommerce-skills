# 评估与商业交付

[首页](../README.md) · [获取帮助或公开询问](../SUPPORT.md) · [授权说明](licensing.md)

## 当前能够直接取得的材料

公开资料版本`0.1.1-public-demo`：十八项功能卡、十八个自足试阅文件、十八组独立输入/编辑参考输出、数据例的五份合成CSV、使用/兼容/授权/证据说明。截图和媒体成片不在本次交付清单内。完整付费Skill正文、私有参考及运行模块不在此仓库。

## 如何评估

按团队的一项明确任务选案例，先看需要哪些材料、应交哪些成果，再自己试阅并比较。公开案例是评估成果形态的入口，不能单凭它判断完整产品的全部覆盖、真实平台权限或经营效果。

可以在[本仓库Issues](https://github.com/Modernlinc/ecommerce-skills/issues)提出不含隐私的产品评估问题，说明任务类别和期望成果。不要放真实账户、客户资料、商业合同或付款信息。

## 完整产品交付前逐项确认

|确认项|应写清的内容|
|---|---|
|产品与版本|所选Skill/组合、版本、适用任务与排除范围|
|实际文件|交付目录与文件清单；哪些是正文、参考、模板或必要运行模块|
|可用条件|支持客户端、操作系统、依赖、所需权限及已验证/未验证范围|
|首次使用|中文入口、必要输入、完整样例、结果检查和安全停止方式|
|授权|个人/团队使用人数、用途、客户服务与再分发边界|
|商业条款|价格、付款与交付方式、适用的退款/售后条件；以双方事前书面确认内容为准|
|更新与支持|覆盖期限、更新接收方式、支持渠道与服务范围|
|接收核对|实际交付版本、目录或ZIP的完整性标识、缺项处理与接收记录|

本页是确认清单，不是已达成的报价、合同或服务承诺。本仓库尚未开放自助结账；没有公布固定价格、退款政策、支持时效或未确认的私人联系方式。不要向评论区的陌生付款链接或个人账号汇款。

## 反馈与后续

公开资料问题走[SUPPORT](../SUPPORT.md)；任何商业交付以正式确认的受控交付渠道为准。不会要求你在公开Issue里上传付费包或真实业务数据。
