# 公开与私有内容边界

[返回首页](../README.md)

|可放入本仓库|不进入本仓库|
|---|---|
|名称、任务、输入输出类型与限制|完整付费SKILL正文、私有参考、专业方法和运行模块|
|新编合成输入、演示输出和文字流程|内部评估答案、历史审查日志和权限规则|
|经过公开许可核对的自有图片|客户/账户/订单数据、私有后台、未授权第三方付费内容|
|版本说明、公开维护脚本|凭证、API Key、Token、Cookie、合同、私有成本|
|公开展示授权说明|付费ZIP、Skill成品压缩包与其他私有分发物|

本仓库从空白公开目录编写，没有搬运完整付费包。新编示例只借鉴产品可公开的任务形态，不重发内部首答或隐藏方法。任何无法确认公开权限的文件均留在仓库之外；忽略规则不是授权核对的替代。

public-demo版本和商业版本独立维护。本次更新不覆盖已安装商业Skill，不改变其准入结论、专业边界或商业许可。
