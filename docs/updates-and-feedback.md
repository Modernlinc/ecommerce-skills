# 更新与反馈

版本以 CHANGELOG、catalog.json 和 Git 提交为准。CONTENT_MANIFEST.json 记录本版十八项 Skill 的完整文件身份。

## 安全更新

1. 在仓库副本运行 `git pull --ff-only`，先读 CHANGELOG；本地有未提交修改时先保存自己的分支。
2. 确认已安装的同名 Skill 是否有个人修改。将旧目录完整移动到宿主扫描范围之外的备份位置，保留版本和修改；不要直接删除。
3. 用安装器重新安装所需项，检查 Skill 列表，跑原来的合成任务作对照。安装器不会自动覆盖旧目录，也不会在后台自动更新。
4. 如有问题，将新版本移出安装目录，再把备份放回。不要同时保留两个同名 Skill 在宿主扫描范围内。

卸载同样由使用者将不再需要的 Skill 目录移出宿主扫描范围；本仓库不提供自动删除脚本。

## 提交有效反馈

在仓库 Issue 中说明 Skill 名称、提交或版本、工具版本、合成输入、实际输出、预期差异及重现步骤。不要提交私人信息或原始客户数据。方法改进应指出具体步骤和依据，新增案例标明合成身份。修复后运行对应检查，并说明已验证与未验证范围。
