# 阅读、试阅与安装范围

[首页](../README.md) · [使用指南](getting-started.md)

|方式|当前可用材料|已确认的范围|不据此承诺|
|---|---|---|---|
|GitHub网页阅读|中英文首页、十八项卡片、输入、参考输出|文本与相对链接可浏览；页面语言见下文|真实平台执行或商业效果|
|复制/上传单项Markdown|十八个单文件试阅|文件内含完整合成题设和交付要求；不依赖私有文件|每个模型必然给出相同或合格结果|
|CSV文字核对|数据案例五份CSV|UTF-8/逗号格式、字段、口径与嵌入题设一致|任意ERP导入、多币种或订单级广告归因|
|客户端原生Skill加载|公开卡片使用SKILL.md元信息|目录名与name、description、metadata按本仓库检查约束核对|所有客户端已安装运行或通过其原生工具验证|
|完整商业产品|随独立交付版本提供|购买前确认实际支持客户端、依赖、文件和验证记录|公开仓库即完整安装包或自动更新器|

首页提供中文与英文两个入口；十八项题设、使用说明和读者核对以中文为主，业务文案依任务采用英文。当前不宣传完整双语覆盖。

文字试阅无需登录业务账户，不安装插件或第三方脚本。支持读取Markdown的工具可用于尝试，具体文件上传能力和模型结果由该工具决定；本页没有给未实测客户端盖章。

版本号只对应公开资料；升级公开目录不会自动升级已安装商业包。完整产品更新应提供新版本、变更说明、适用环境和交付校验信息，经接收方确认后切换。
