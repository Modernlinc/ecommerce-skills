[首页](../README.md) · [18项目录](skill-catalog.md)

## 示例：多文档价格更新

打开 [Codex合成输入](../skills/codex-ecommerce/examples/input.md) 和 [公开卡片](../skills/codex-ecommerce/SKILL.md)，把两者内容交给你正在使用的AI工具。

可以这样委托：

> 请按这张公开演示卡片处理附件中的合成任务。交出三份完整英文新版文字，列明同步位置，未知事实保持未知。不访问真实后台，不操作账户，不执行发布。完成后明确说明实际做了什么。

先保存第一版回答，再看[参考输出](../skills/codex-ecommerce/examples/output.md)。检查三处是否都变为44 USD、规格和限制是否保留、有没有自行添加运输或税费承诺。参考输出是编辑制作的合成工作稿，用于核对成果形式和事实一致性。

## 使用方式和安装边界

读Markdown即可试阅；不需要运行脚本。若要用支持Skill文件夹的客户端体验，只选择单项公开目录，并按该工具的官方说明加载；本仓库不自动复制到用户配置、不修改模型或插件、不安装依赖。客户端能读取一份文件不代表完整商业包已安装。

## 何时停止

缺输入时先指出具体缺项。真实账号、广告花费、消息发送、店铺改写、支付、库存、客户资料或专业财税结论超出本演示，停在准备好的草稿和交接项。不要为了跑通案例而填造事实。

## 资料维护检查

在本仓库根目录运行Python 3.10+：

```bash
python3 scripts/validate_structure.py
python3 scripts/scan_public_leaks.py
python3 -m unittest discover -s tests -v
```

检查只读取候选树，不运行广告、店铺或外部API；也不会自动发布。结构、链接和泄漏扫描通过，不等于专业方法、真实效果或跨工具兼容性已经验证。
