[首页](../README.md) · [十八项目录](skill-catalog.md) · [详细使用说明](getting-started.md)

不用先读完十八项。从最接近眼前工作的一个案例开始。每份试阅已经包含完整合成材料、委托要求和核对清单；复制全文或保存这一份Markdown后交给能读取它的AI助手即可。

## 怎么开始

1. 选择一份试阅，复制全部内容或保存文件。
2. 交给你已有的AI助手，附上下面这段委托。
3. 保存回答，先按题设末尾清单自己检查，再打开参考输出。
4. 愿意反馈时，告诉我们是哪一项、卡在哪一步、缺了什么成果。

可复制的委托：

```text
请按我提供的这份公开合成试阅完成任务。只使用文件内材料，交齐要求的完整成果，不读取参考答案，不执行真实账户或平台操作。完成后列出仍然未知的事项及下一步。
```

这里需要你自己可用的AI工具；其订阅或用量条件以该工具为准。本仓库不提供在线模型运行服务，不收取或保存你的AI对话。

## 三个检查点

- **交齐了吗？** 需要的完整文稿或表格都有，而不是只给修改建议。
- **事实对吗？** 价格、数量、规格和日期对应题设，未给的内容保持未知。
- **知道下一步吗？** 哪些可以继续编辑，哪些要补资料，哪些真实动作尚未执行。

公开试阅帮助你判断任务和成果形态是否适合；参考是编辑编写的工作稿。这个过程不代表完整商业方法已交付，也不证明每种模型或客户端的结果均通过验证。完整产品的具体版本和环境另行确认。

## 试完之后

通过[仓库反馈入口](https://github.com/Modernlinc/ecommerce-skills/issues/new/choose)选择“Trial feedback / 试用反馈”，或按[SUPPORT](../SUPPORT.md)格式说明。GitHub发Issue需要GitHub登录，阅读和保存公开题设无需业务账号。

只需报告任务、使用工具名称（可选）、体验状态和去敏的短摘录。不要发客户材料、账号、付费包或内部思考过程。没有试完也可以说明卡点；没有反馈不会被当作已经试用或验收。

想做其它任务？返回[十八项目录](skill-catalog.md)。想核对完整包应该交付什么？看[交付前确认清单](evaluation-and-delivery.md)。
