# 演示与证据说明

[产品首页](../README.md) · [使用指南](getting-started.md)

## 本版实际提供什么

十八个自足题设、对应功能说明和十八份编辑参考工作稿；数据例另提供五份CSV。这些是原创合成文字材料，说明输入、成果形式、核对和交接，不是模型独立运行记录。截图或成片不属于本版交付清单。

|证据类型|能说明什么|不能说明什么|
|---|---|---|
|本版合成题设/编辑参考|材料和完整工作稿的样子、算式与未知处理|真实客户、销量、GMV、利润或ROAS成绩|
|读者自己的试阅|该次模型在该题设上的实际回答|未经保存回读的动作，或全部商业Skill能力|
|未来示意图|工作流程和信息关系|真实后台截图、API执行或平台资格|
|未来运行演示|有权限且有真实记录的具体动作|整个平台、所有客户端或真实经营效果|

镜头计划与素材brief不等于拍摄、配音或成片。不能绘制假后台来填补“截图缺项”。如未来新增媒体，需写清文件、来源、日期、许可和类型。

## 数字与口径

价格、数量、日期、预算与算式均是题设。数据例ROAS6.0仅表示合成120÷20，不是经营表现；已列费用范围贡献不等于净利润。学习量、来源质量或研发投入的对外数字必须另有真实统计，不从文件体积或文件数推算。

## 变化与未知

每项案例独立使用自己的商品事实；题设更新时要同时更新试阅、输出和目录。未知不能按零填补，撤回证据后撤回依赖结论。平台政策、价格、资格、界面与API要求在实施当天核验，本版不作实时政策通过声明。
