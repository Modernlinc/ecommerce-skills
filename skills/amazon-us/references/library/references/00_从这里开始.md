# Amazon美国站商品与经营材料：从这里开始

这套方法供卖家协作者在能读取本地文件的AI中，使用获准的商品和经营材料，准备商品文字、履约差异、费用与现金核对、通知纠正草案及Sponsored Products广告建议。说清你要解决的问题即可，不必先填完整经营表。

## 第一次怎样用

把整个文件夹交给能读取本地文件的AI，复制下面这段话，并写上你的目标和已获准材料：

> 请读取“方法__METHOD.md”、输入输出约定，并按我的问题选择所需方法。我的目标是【具体问题】，可读取的材料是【明确获准的文件或正文】。请先给主要判断，再交本次需要的完整稿件、计算或方案，解释取舍和未知，最后给一个下一动作。缺项时继续完成有依据的部分。只作离线准备，不登录或执行平台动作。资料涉及真实客户或敏感信息时，先停在读取之前确认具体范围。

AI应实际读到[方法入口](方法__METHOD.md)、[输入约定](方法__contracts__INPUT.md)和[输出约定](方法__contracts__OUTPUT.md)；无法访问就说明缺什么，不能声称已加载。完整经营复盘需读取五篇领域方法；局部任务只读相关部分。

## 按问题提供材料、取得成果

| 眼前的问题 | 先准备什么 | 应取得什么 |
|---|---|---|
| 两款商品共用旧稿；包装或目录数量不一致 | 商品规格、销售单元、各SKU差异、现有稿件；有目录材料时附站点和日期 | 各SKU完整标题、要点或描述；身份冲突、共用与独有说法的证据说明。见[商品与Offer](方法__references__01-product-and-offer.md) |
| 发出与接收对不上；库存和交件承诺不一致 | 各批次数量、单位、日期；FBM另给队列、容量和截止条件 | 数量差异、条件排程和完整内部核对稿。见[履约库存](方法__references__02-fulfillment-and-inventory.md) |
| 退款是否已扣；本期贡献和现金能算多少 | 获准的金额摘要、期间、已含关系；现金收付另列 | 收入桥接、逐行费用、可复算小计、仍缺项及独立现金说明。见[贡献与现金](方法__references__03-contribution-and-cash.md) |
| 账户健康、通知回应、退款与退回实物不一致 | 在确认读取权限后，提供对应对象、事件时间、处理阶段和凭证摘要 | 流程分路、时间线、有源时限核对、完整未发送草案和金额/实物核对。见[账户与售后](方法__references__04-account-and-returns.md) |
| 搜索词取舍、SP结构、广告变更 | 商品事实、获准逐词报表、期间、资格及经营约束 | 逐词取舍理由、结构及有条件的变更草案。见[Sponsored Products](方法__references__05-sponsored-products.md) |

商品、查询或历史竞品材料可用普通中文或已有表格；金额附币种，数量附单位，每条记录保留自己的时间。缺失写“未知”，不要用0填补。查询份额、短窗口与历史样本不直接代表全年销量或经营效果。

使用者自有且无个人/客户敏感信息的商品事实、明确获准的非敏感经营摘要，可以按合同用于新任务。真实客户/订单资料（含脱敏件）、账号信息、银行支付/合同税报或其他敏感材料，必须在读取前另行确认具体对象和范围；不要先上传原件。没有此类授权时，可用自己编写的安全合成情境或公开商品事实理解方法，并如实标明来源性质。

## 怎样检查结果

先看是否交了本次需要的完整稿件、对账或方案，再核SKU、销售单位、金额、期间和证据是否对应。商品对外正文与内部备注应分开。贡献、现金、申请、批准和到账不能互相替代；算式应可复算，未知应紧邻受影响的判断。有一项缺证不应抹掉其他有证成果。

账户售后任务还要检查：通知对象和阶段是否分开，时限的事件、单位和时区是否有依据，退款与实物状态是否分别核对。AHR恰100不能直接认定恢复；SAFE-T时限长度、起算和运输丢损资格必须分别判断；起算有冲突时不能选更宽截止放行；FBA估值异议时限不能套到全部资格拒绝。详细适用和未决条件见[当前限制](方法__LIMITATIONS.md)及[政策证据映射](方法__provenance__K04_POLICY_EVIDENCE_20261020.md)。

## 补材料或改目标后怎样继续

在同一对话说明是纠正原记录、增加新事件，还是更换目标。例如：“蓝色款包装数量已改，灰色款未变；请交受影响文字的完整新版，并保留仍成立的内容。”AI应撤回失效结论、检查相邻依赖，交受影响部分的完整结果；不只给补丁，也不无故重做无关部分。新包装不自动改历史订单，新费用不自动改银行到账，申诉已提交不等于限制已解除。保留原材料和原结果，新结果另存。

## 使用环境、文件和版本

这是供AI手动读取的方法文件夹，没有后台账户、自动安装或平台连接功能。公开链接是出处；离线阅读不自动打开网站。涉及当天政策的实际决定仍需相应的当前证据，不能把保存日期当成永久有效。

当前包装ID为AMAZON-PRACTICAL-20261020-P1，版本2026.10.20-amazon-p1.1；20件文件，以根[MANIFEST.json](MANIFEST.json)为唯一当前清单。本包从冻结R3方法整理而来，只调整文件组织、导航和身份说明。来源方法中“候选/待独立复核”等文字保留其冻结时点，不作为当前质量裁决。方法源R3已在声明的离线用途内获PASS_WITH_EXCEPTIONS；本文件包仍需总控核对封装完整性。不是正式库采用、公开上线或真实效果验证。

本包不附历史测试答案、内部审查报告或私有知识库。需要核来源、日期、成熟度和许可时读[范围与来源说明](02_范围与来源说明.md)。没有任意宿主兼容、真实业务效果或自动更新保证；真实上架、广告花费、退款、申诉、采购、库存和客户联系仍须另行授权。团队使用、商用成果、再分发、更新、支持、定价与退款条款待Owner统一决定，不由本文件设定。
