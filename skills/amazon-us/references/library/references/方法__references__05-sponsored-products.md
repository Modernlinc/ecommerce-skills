# Sponsored Products 与经营复盘

原SP部分为研究与草案，继承2026-09-06文字选段；首次发布日期unknown保留。现行官方准入不以首发未知单独阻断，但旧选段未因此成为今天核验，具体适用仍检查正文/市场/时点。[SP对象](https://advertising.amazon.com/solutions/products/sponsored-products)说明CPC商品广告及图片/视频、Amazon与部分外部展示；[新广告主指南](https://advertising.amazon.com/library/guides/new-advertiser-success-guide)涉及账户/商品/Featured Offer/库存条件。它们不能证明本卖家资格；KDP/vendor等类型也不能互换套用。

## 资格与经营先读

确认广告主类型、站点、商品/offer、品类资格及可售/Featured Offer证据；“有资格参与”与“当前展示Featured Offer”不同。未证处写unknown，合成前提不当实盘许可。再接回商品身份、履约、现金和健康通知。预算存在不是付款授权，账户健康总分不是商品安全放行。

## 对象和结构

按campaign→ad group→广告商品与定向目标形成解释性结构，不输出上传枚举。不同履约/包装或受不同风险约束的商品分开审阅，是否拆campaign由可观察的目标/预算/归因需求决定，不机械要求每SKU一个campaign。

[定向指南](https://advertising.amazon.com/library/guides/targeting-with-sponsored-products)区分顾客查询与投放关键词，以及自动、手动关键词/商品和否定；自动四组名称close/loose/substitutes/complements可识别，异常商品例子不采用。该页部分示例前后不一致（CF03），不得用它判真实商品关联或造兼容性。广泛/词组/精确只是定向选项，不提供当前批量上传格式。

公司候选结构通常可将探索与有证据的意图验证区分；只有输入有合法明确的品牌/商品目标时才出对应草案。缺真实ASIN映射的产品目标保留待证，不造编码。

## 逐查询与变更理由

每条报告保留查询/目标原值、商品事实关联、匹配来源、展示/点击/支出/归因销售与窗口。优先判断卖的究竟是整品、配件还是服务，再看数据。
- 明确不相关：可以给范围窄的否定草案及误伤检查；理由来自商品事实，不由“花了钱没订单”单独判。
- 相关且有转化：保留观察或候选精确意图草案，但退款/贡献/资格不齐不得扩量放行。
- 相关但样本少或归因未成熟：列观察原因、下次要补的窗口和证据，不能判无效。
- 产品目标身份不清：保留不识别，不按字符形状认定真实ASIN。

每项变更写清当前对象、拟改内容、证据、前提、误伤/相邻风险和复查/停止；不实际更改出价或预算。官方营销建议中的固定点击数、两周、评价数、日预算等不成为通用门禁或必胜参数；经营策略缺独立实践时保持假设。

指标计算按[03](方法__references__03-contribution-and-cash.md)。当前报表金额可统计但归因未成熟不能判最终转化；不把所有期属混成因果。综合优先次序先处理具体资格/安全阻断，再修身份/履约/利润证据，最后才讨论有界实验。没有经济约束时可交有用结构草案，执行HOLD，不能自己发明预算。

## 查询报表与分母检查

这里扩展离线诊断，不把Brand Analytics当作SP广告报表。当前官方对象依据为2026-10-10可读的[Brand Analytics说明](https://sell.amazon.com/blog/brand-analytics)；仅逐命题采用可读定义。详见[本轮来源映射](方法__provenance__ROUND_TWO_SOURCE_MAP.md#d1-查询分母)，不证明具体账户资格或窗口已核。

| 报表或材料 | 先识别的对象 | 不可直接推出 |
|---|---|---|
| Search Catalog Performance | 选定期间内的商品搜索互动 | 某一查询或单个广告的表现 |
| Search Query Performance（SQP） | 查询＋Brand/ASIN视图及各阶段指标 | 绝对转化率、独立人数、广告增量效果 |
| Top Search Terms | 每查询前三个被点击商品及其点击/转化份额 | 全部竞品、销量排序或未出现商品为0 |
| SP搜索词/定向报表 | 广告对象、定向、查询和各自归因字段/窗口 | 整个搜索市场或与SQP同口径 |
| 第三方工具表 | 标明原始数据、转换方式、采样/估算及工具时点 | 自动等同官方原始计数或卖家实账 |

按以下顺序处理：

1. **固定范围。** 保留原报表名、原表头/值、native或vendor来源、站点、Brand/ASIN/广告对象、query原文、期间、时区及导出时点；同时记录筛选、TopN、舍入/抑制和字段定义。query volume、impressions、clicks不是同一分母，也不等于独立顾客。缺字段时先说明影响，只索取会改变本次决定的最小输入。
2. **验算同阶段份额。** 同一对象/期间/阶段且总数T>0时，核对主体数N÷总数T。展示精度已知才依相应舍入区间判断；未知时保留算式差异，不设万能容差。计数、份额矛盾则隔离受影响行及其量化诊断，不猜改原数；缺失、0、抑制分别记录。相邻完整行仍可继续。
3. **再判断比值能否比较。** 只有事件、计数、对象和窗口已证相容，才给clicks/impressions或purchases/clicks等公司派生事件比；未核平台定义时不自动命名为平台CTR/CVR。同一总体、同一口径、所需分母非零时，“购买份额÷点击份额”等于“主体购买每点击÷总体购买每点击”的条件代数比；它不是绝对转化率，不代表顾客实际流向，也不能证明需求未满足。跨报表、异窗或只有百分比而定义不清时不推导该比。
4. **定位待检环节，不先定原因。** 依有证数据选择线索：曝光可查相关性/可见资格；点击可查查询意图、呈现、报价/配送；加购可查规格、组合、兼容和页面事实；购买可查可购买状态、配送、报价与信任。这是公司审阅分路，不是排序规律。为关键假设列出可区分的替代解释及下一证据；缺哪个阶段就止于能支持的层级。
5. **交付内容和有界下一步。** 将有效查询回接K01事实，再接回K02–K04单位、供货、贡献、现金和通知限制。有证时给完整待审标题/要点/说明及理由；无证功能不写成事实。只提出一项最高优先补证或离线改稿。实验草案须有基线/对照期间、一个改动、混杂因素与停止/回退条件；不自定预算、折扣、竞价、补货数、固定点击门槛或默认观察天数。

不要用SQP份额相减求“自然流量”、把SP归因订单和查询购买计数混加，或从汇总数据推断个人路径。品牌份额也不能自动分配给某个ASIN。教程的24小时窗口、画面异常数值、促销/图片合规说法和未来工具功能均未成为当前规则。当前方法为company_design；实际经营改善仍method_hypothesis，须后续受控项目证据验证。
