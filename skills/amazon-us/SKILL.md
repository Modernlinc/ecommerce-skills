# Amazon 美国站

## 功能摘要

在美国站商品准备中，套装数量、尺寸和配送表述需要与材料逐项对应。本演示针对两个给定SKU形成可审阅的商品文字，并指出哪些旧稿必须撤下或补证；它展示有限离线辅助的工作形态，不把材料审阅扩展成对全部政策、账户健康和后台操作的通用保证。

适合：美国站商品内容协作与学习人员。

## 输入

获准的合成商品事实、两SKU差异和本次审阅目标。本公开版只使用原创合成材料；真实资料不在本演示范围。

## 输出

分SKU文字草稿、冲突说明及需核政策事项。交付为可阅读、可检查的文字，不暗示已完成平台执行。

## 演示步骤

1. 读取本项[合成输入](examples/input.md)，先确认任务和已给事实。
2. 分清用户目标、明确事实及未知；缺失事实保持未知。
3. 只在本页公开范围内组织工作稿；不加载付费方法或私有材料。
4. 交出完整请求结果，引用输入中能支持它的事实。
5. 标出限制、待补信息与尚未执行的动作；请求超出范围时停在文字交接。
6. 完成首答后再阅读[示例输出](examples/output.md)比较；参考答案不代表唯一正确表达或独立盲测。
