# 中文快速开始

当前入口与用途见[中文入口](../../../00_从这里开始.md)及[能力与来源](../../../02_能力与来源.md)。

本包需 Agent 读取，不是可执行程序。“自包含”只指随包依赖齐备，不表示完整 Display/Video、任意宿主或销售许可已经验证；本次封装待复核，不授权花费。
在已获准读取本包的Agent会话中明确提供本目录[入口](METHOD.md)，然后说：

“使用这套Google Ads Skill，按我提供的业务目标、商品或页面资料，给一份可审查的投放方案；缺信息请明确指出，不登录账号、不改预算、不发布。”

附市场/语言、要达成的业务结果、已有页面事实、允许动作和损失边界即可；没有的写不知道。不要发送客户/账号资料。Agent按任务读取参考文件。
拿到结果后看：承诺是否来自你给的事实；付费结果是否被浏览量替换；预算是否凭空出现；有没有实际文案和明确的下一证据。显示PAUSED不表示平台中有广告。
先看[Search示例](examples/search-review.md)了解输出及末尾改稿分支，也可看[商品变体分支](examples/merchant-review.md)；它们是示范答案，不应拿它冒充一次新执行。加载失败或无法使用工具时见[使用说明](USER_GUIDE.zh-CN.md)。
