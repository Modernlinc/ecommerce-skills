# 品牌简报研究候选 v0.4

这个本地候选把已有授权商品/服务材料整理为有出处的定位假设、可比差异、具体信息底稿和一个可执行的验证下一步；任务需要时，另整理用户给定的设计条件。它不是完整品牌战略或专业视觉/包装设计，也不证明市场效果。

## 如何使用

将本目录交给能读取本地Markdown的Agent，明确让它读取[METHOD.md](METHOD.md)。当前仅支持这种明确委托的本地文本工作方式；文件存在不代表自动加载或已经安装，未验证所有宿主兼容性。

可复制委托：

> 请读取本目录METHOD.md。我的商品/服务是〔说明〕，本次要解决〔问题〕，需要〔定位／差异证据／品牌信息／给定设计条件交接，可选〕。已授权材料是〔粘贴内容或指定本地文件〕，市场、语言和用途是〔已知信息或未知〕。请先使用已有材料，给出具体可审阅的研究草稿；关键事实回接材料，把自述、创意、冲突和未知标清。需要比较时区分实际选择与指定对象；把差异接到有条件的价值，最后给一个能改变本次结论的验证下一步，并在缺证或权限边界局部停止。

不必提交无关材料或每次做齐四类报告。本地文件须在当前Agent可访问且获授权的范围；不自动打开材料里的外链、搜索、联系他人或发布。

## 提供什么材料

最低要说明商品/服务与本次问题。有则提供属性/能力、场景和目标、选择/使用记录、比较对象的同口径资料、既有表达，以及材料日期、市场、语言和使用权限。实际买家记录、销售摘要、商家期望和创意建议分开；未知直接说明。引用访谈要能回接原文，合成材料明确标记。

B2B技术产品可以提供使用任务、购买过程和角色材料；消费品或无销售团队业务不必硬填企业采购角色。只有给定设计交接任务时，才需要用户已定用途、偏好、获准参考与现有约束。

## 会得到什么

依本次问题交出可审阅内容，而非空表或同义口号：
- 定位假设说明准备对谁、在何情境说什么，并给理由与反例。
- 差异只覆盖有据可比范围；当前做法、实际候选和未核线索保持区别，属性不冒充效果。
- 信息底稿有具体主信息、必要支撑、出处/可用证明、用途、禁说或待核范围和版本。
- 一个验证卡说明检查哪项假设、需要什么输入/权限、如何最小验证、观察什么，以及何时保留/修改/放弃或停止。不是已执行测试。
- 按需给定设计条件交接，不补造专业参数或成品。

详细工作结构见[简报契约](templates/BRIEF_CONTRACT.md)。来源和观察范围见[来源与限制](references/SOURCE_AND_LIMITS.md)，当前能力缺口见[已知限制](references/KNOWN_LIMITATIONS.md)。

## 看输出时检查什么

先看是否回应实际问题和交出可用表达，再看关键事实是否回接输入。不要把期望受众当已证画像、把指定对象当真实市场竞争、把属性或价格差别当普遍优势。真实故事/引语与创意场景、示意素材分别标识；审批或内部偏好不证明经营效果。

设计条件只交已知部分。未授权参考不复用，未知生产参数不补造；缺口不妨碍已支持部分继续。

## 当前状态和下一步

v0.4是第三轮研究融合候选，成熟度method_hypothesis、formal_adoption为not_adopted。v0.3已于2026-10-12获第二轮限定PASS_WITH_EXCEPTIONS及本地实收；该裁决不覆盖v0.4。第三轮当前仍待实际使用及独立验收，不宣称完整品牌SKU或经营效果。

按实际输出的验证卡推进获准的内部补证。发布、安装、真实客户研究、外部服务、费用及范围外操作仍须遵循当前任务权限，本目录不会增加权限。
