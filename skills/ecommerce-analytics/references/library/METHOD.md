# 广告与电商离线核算实用版 V1

先读 [使用入口](00_开始使用.md) 与 [输入合同](references/input-contract-v1.md)。本版本接受合同内的新 ID、金额、日期及记录组合，不锁旧样例；仅当本次资料对象与用途已获准时执行。

1. 在读正文前，确认来源类别、精确文件、使用目的及权限。真实客户/订单/银行/隐私资料，包括脱敏件，先向 使用者 取得对象级许可和处理方案。本版本现有验证仅使用原创安全资料；不要让用户先上传，也不靠文件中的授权标签自授权限。
2. 确认本机为受支持的 Codex 本地宿主，使用当前 `load_workspace_dependencies` 返回的运行时。缺失或版本不符停止，不安装、下载、复制依赖或改用系统 Node。
3. 包根 P 只读，由脚本自身定位；使用者明确选定独立的工作区 W。核对 W 中任务授权、合同、五表和新运行 ID。拒绝软链接、路径逃逸、交叠、已有目标；不要扫描其他资料或自动换名绕过拒绝。
4. 调用 `scripts/reconcile_v1.mjs`。本包只运行该程序，不依赖旧程序、历史输入输出或制作方检查脚本。金额与状态由唯一工作簿公式计算，保存重开重算后生成诊断与 JSON；不得手填结果。
5. 检查实际输出、来源格和局部未知。金额缺失不填0、已知小计不称总额、贡献不称净利润、自报 ROAS 不称去重收入；事件异常不改收入。解释可证差异、可能原因、下一证据及安全停止点。
6. 新事实进入新 revision，以新 run ID 真实再运行；需要比较时指定同 job、同一冻结包 SHA-256 的已完成旧 run ID。异包或身份缺失安全拒绝，不能仅凭版本名相同直接比较；跨包差异解释须另行验证。旧输入、旧工作簿和旧回执保持不变。修改 Excel 不会重建所有关系或更新外部诊断。

输出是 `核算结果.xlsx`、`核算诊断.md`、`结果快照.json`；运行回执与图片在同一 run 的 evidence 中。主工作簿的金额、状态、覆盖与原始格保真需实测；导出或生产者检查成功不等于独立终验、原生 Excel/WPS、第二台 Mac 或真实经营验证。

不连接账号，不执行广告预算、支付、退款、库存、SQL、Production、Vercel、Shopify live 或公开发布。方法出处与适用限制见[方法来源与限制](references/method-sources-and-limits.md)；该说明不构成独立验收或真实经营证明。遇超出合同、依赖不兼容或需要新增权限时保存准确失败证据并停止受影响动作。
