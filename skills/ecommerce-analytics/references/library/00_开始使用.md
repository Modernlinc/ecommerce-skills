## 首版环境与文件

首版仅针对 macOS Apple Silicon 的 Codex 桌面本地会话，需能调用 `load_workspace_dependencies`。当前运行配置为 bundle 26.1017.11052、Node 24.19.0、Python 3.12.14、Artifact Tool 2.8.99、openpyxl 3.1.5。先由 Agent 在当前宿主发现这些依赖；不把本机缓存路径作为买家固有路径，不自动安装或随包复制依赖。其他运行时、系统、第二台 Mac、原生 Excel/WPS 均未验证。

包目录 P 可搬移，程序从自身位置找资源；工作区 W 由你指定，P/W 不能相互包含。W 的 `runtime/LOADER_BINDING.json` 记录本次 loader 返回值：`discovered_by`、`bundle_version`、`node`、`python`、`packages`。Agent 必须先真实调用 loader，不能填一个未经核实的路径。

在 W 下准备：`authorizations/<job>.json`、`jobs/<job>/inputs/<revision>/INPUT_CONTRACT.json` 及同目录五个 CSV。从 [合同说明](references/input-contract-v1.md) 和 [空合同模板](templates/INPUT_CONTRACT.json) 起步；不要把空模板当可运行案例。每次运行使用全新 run ID，生成到 `jobs/<job>/runs/<run>/`，分 outputs/evidence/staging；授权文件不代替人类授权。

使用 loader 返回的 Node 启动：

```text
NODE P/scripts/reconcile_v1.mjs --workspace ABS_W --job-id JOB --authorization ABS_AUTH_JSON --input-contract ABS_INPUT_CONTRACT --run-id RUN --runtime-python LOADER_PYTHON --runtime-packages LOADER_NODE_MODULES
```

参数都是本次明确对象，不能省略路径后让程序自行寻找。`--help` 只帮助；缺参、未知参、安全拒绝均不补路径或覆盖旧文件。失败 run 保留，不把失败日志改成成功。

## 读结果与继续

先看工作簿“核算与诊断”：数值与状态分列；来源格可追到“订单核算”及五张源表。`n.a.` 是缺证/不适用，不是0。范围贡献排除税和未纳入的成本，不是净利润或银行到账；平台自报 ROAS 不能直接横比或相加当去重收入。CPA/CAC 需要另有动作/新客户定义与分母，不在本版本新增算法。

note 中的 `#N/A`、`#REF!` 等字面文本按原文保留，不视为计算错误；真正的公式错误仍阻断完成。

再看中文诊断的具体缺口与下一证据。补证放新 revision，更新具名授权输入清单并用新 run ID，追加 `--previous-run-id PRIOR_RUN`。程序真实重算、保存重开后仅比较同 job、同一冻结包 SHA-256 的实际快照；窗口、截至日或口径变化会标不可直接比较。异包或身份缺失以 `PREVIOUS_PACKAGE_MISMATCH` 拒绝，即使版本名相同也不直接比较；包改变时作为独立运行，跨包差异解释须另行验证。本版不自动迁移或混合比较。旧结果不覆盖。

生产者验证、独立检查、真实业务和公开发布是不同阶段。方法来源与适用限制见[方法来源与限制](references/method-sources-and-limits.md)。本包不含历史样例、旧程序或制作方检查脚本，按上文从本次获准的新五表开始。
