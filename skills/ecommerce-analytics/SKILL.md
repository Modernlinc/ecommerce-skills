# 广告与电商数据核算

## 功能摘要

在明确五表口径下展示贡献核算与缺证影响。方法、模板、相关脚本和示例均随本目录提供，免费使用，许可见 [LICENSE](LICENSE)。

## 输入

- 五份合成CSV或本页相同数据块
- USD/日期/订单关联与费用口径
- 支付费用证据撤回情景

先确认本次任务、对象、目标和材料使用权限；缺失事实保留未知，不从示例补造用户事实。

## 工作流程

1. **先读取 [完整方法入口](references/library/METHOD.md)**，再按它的导航读取本次任务所需的参考、合同和模板。所有路径以所在文件的目录为准；引用前的 `@` 与普通相对路径同义。本目录外没有运行所必需的项目资料。
2. 使用用户本次提供或明确授权的材料，按方法完成判断和所请求的完整成果，不只复述流程或列出工具。
3. 将商品/业务事实、来源观点、假设和未知分开。需要当前政策、价格或资格时核对适用官方资料；无法核实则保留待核。
4. 交付前核对成果中的主张、单位、日期、范围和引用是否匹配输入。跟进时更新受影响的完整稿，保留仍有效的内容。
5. 需要脚本时先检查运行环境、输入和输出位置，再运行该脚本；未运行不能报告执行成功。真实账户、广告支出、发布、支付或库存操作不由安装授权。

## 输出

- 四项核算的逐步算式与结果
- 平台归因和订单口径说明
- 费用撤回后的保留/撤回结果

同时交代关键依据、未确认事项及下一步；不要求使用者拼接互相冲突的旧稿。

## 限制说明

按五表输入合同处理获准新CSV，实际生成17项核算、公式工作簿、诊断和快照，补证后同包重算；限定当前Mac/Codex运行时。

方法库保留形成时的适用边界、日期、来源归属和验证限制。历史“候选／内部／待验／平台”说明描述当时用途与验证状态；本公开版本允许任何人按 MIT 使用与贡献，这不将历史案例变成真实经营验证。历史字节清单只供追溯，本安装副本的文件身份见本 Skill 目录的 `CONTENT_MANIFEST.json`。历史安装命令与旧字节校验清单只供追溯，不作为当前安装步骤；安装以仓库使用指南为准。旧的发布审批及商业交付描述不适用于本开源版本；材料权限、事实核验和真实操作安全边界仍适用。

本 Skill 的 Excel 自动核算需要支持 `load_workspace_dependencies` 的 Codex 宿主及其返回的工作簿运行环境。普通聊天工具可阅读方法与模板，但不能据此承诺自动生成工作簿；依赖不可用时停止该脚本并说明缺项。完整合同五表与快速算例的五份 CSV 是不同格式，不能混用。
