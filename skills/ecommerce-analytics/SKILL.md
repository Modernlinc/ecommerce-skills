# 广告与电商数据核算

## 功能摘要

将订单净额、退款、商品成本、支付费用和广告支出拆开看，避免把缺失费用当零或把平台归因金额当真实利润。本公开示例用一组明确的五表输入给出可手工核对的算式，并演示撤回一项费用证据后哪些结果变为未知；完整运行兼容性以交付版本的实际测试范围为准。

适合：需要核对订单、退款、费用和广告口径的人员。

## 输入

固定格式的合成订单、明细、退款、费用和广告五表。本公开版只使用原创合成材料；真实资料不在本演示范围。

## 输出

可核算数值、逐项算式、未知项与口径说明。交付为可阅读、可检查的文字，不暗示已完成平台执行。

## 演示步骤

1. 打开[单文件试阅](examples/demo.md)，将该文件整体复制或上传给能读取Markdown的AI助手；本页无需再复制。
2. 按文件里的任务处理合成输入，不登录、不安装依赖，也不读取参考输出代答。
3. 保存自己的完整结果，按试阅文件的交付清单与逐项核对点检查。
4. 再看[编辑参考输出](examples/output.md)比较事实、交付形式和未知项处理；不要求逐字相同。
5. 若缺输入，指出具体缺项并停在文字交接。参考输出不是AI独立运行或完整商业Skill验收的证明。
