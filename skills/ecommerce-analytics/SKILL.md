# 广告与电商数据核算

## 功能摘要

将订单净额、退款、商品成本、支付费用和广告支出拆开看，避免把缺失费用当零或把平台归因金额当真实利润。本公开示例用一组明确的五表输入给出可手工核对的算式，并演示撤回一项费用证据后哪些结果变为未知；完整运行兼容性以交付版本的实际测试范围为准。

适合：需要核对订单、退款、费用和广告口径的人员。

## 输入

固定格式的合成订单、明细、退款、费用和广告五表。本公开版只使用原创合成材料；真实资料不在本演示范围。

## 输出

可核算数值、逐项算式、未知项与口径说明。交付为可阅读、可检查的文字，不暗示已完成平台执行。

## 演示步骤

1. 读取本项[合成输入](examples/input.md)，先确认任务和已给事实。
2. 分清用户目标、明确事实及未知；缺失事实保持未知。
3. 只在本页公开范围内组织工作稿；不加载付费方法或私有材料。
4. 交出完整请求结果，引用输入中能支持它的事实。
5. 标出限制、待补信息与尚未执行的动作；请求超出范围时停在文字交接。
6. 完成首答后再阅读[示例输出](examples/output.md)比较；参考答案不代表唯一正确表达或独立盲测。
