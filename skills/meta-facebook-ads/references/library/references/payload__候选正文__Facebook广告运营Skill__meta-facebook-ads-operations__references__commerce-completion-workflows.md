# 电商广告完整任务衔接

这是候选包的导航与交付组织，不是新平台规则、统计引擎或商业效果验证。五模式/五状态、L0和因果false仍由[入口](payload__候选正文__Facebook广告运营Skill__meta-facebook-ads-operations__METHOD.md)控制。只收集当前决定所需材料，未知仅阻断依赖它的结论，不要求用户先会英文键。

## 经营与创意复盘

适用：用户同时问素材该怎么做、数据说明什么、贡献和下一动作。先读[经营公式](payload__候选正文__Facebook广告运营Skill__meta-facebook-ads-operations__references__business-math-and-unit-economics.md)、[诊断](payload__候选正文__Facebook广告运营Skill__meta-facebook-ads-operations__references__testing-diagnosis-and-stop.md)、[运营剧本](payload__候选正文__Facebook广告运营Skill__meta-facebook-ads-operations__references__course-distilled-operating-playbooks.md)§2–4/6/8；事件/归因再读[测量](payload__候选正文__Facebook广告运营Skill__meta-facebook-ads-operations__references__measurement-attribution-and-events.md)。

1. 将用户材料按商品/页面、研究/创意、平台观察、订单/退款、结算/成本、变更/容量分组，保留版本/定位；不把标签一致当数值对账成立。
2. 输出研究与主张账：原始摘记/同源重复/反例分开；已有商品事实可形成受限brief，未知尺寸/效果/权利不能编。每个概念说明任务、一个理解变化、证明方式与CTA/页面承接，未看成片就不签成片QA。
3. 给读者一张可算/不可算表。公式只引用math；分开原始收入、税退款、已在结算扣除的费用与V/O/A池，先查原商品/订单到收款的解释。输入声明不一致时保留条件计算，不能称已对账结果。
4. 解释平台与业务两层，定位最早有证断点及替代解释；不把订单数当新客，不把观察CPA差当创意因果或扩量许可。
5. 给一份完整中文报告、具体受限brief和一个主要补证/验证动作，附owner、检查字段、等待、最大损失/花费分栏、停止和回滚。后续条件与现在执行分开。

[F3输入](payload__候选正文__Facebook广告运营Skill__meta-facebook-ads-operations__examples__f3__INPUT.md)及[生产者输出](payload__候选正文__Facebook广告运营Skill__meta-facebook-ads-operations__examples__f3__OUTPUT.md)展示此路径；其中900差额来自该例，不能写成所有项目的固定检查答案。无经营资料时保留可用brief，相关贡献/现金未知。

## 目录、许可生命周期与迁移交接

适用：用户需要多变体/跨市场目录审核、再营销与迁移方案。读[剧本](payload__候选正文__Facebook广告运营Skill__meta-facebook-ads-operations__references__course-distilled-operating-playbooks.md)§1/2/5/7/8、[权限](payload__候选正文__Facebook广告运营Skill__meta-facebook-ads-operations__references__permissions-and-live-gates.md)、[结构](payload__候选正文__Facebook广告运营Skill__meta-facebook-ads-operations__references__meta-ad-structure-and-draft.md)；经营阈值只回math。

1. 按市场/币种/时区/Offer与版本划清集合；把独立关系意图与待核item/variant/content/order指针分开。逐行报告正确/冲突/未知，单行错误不掩盖也不抹掉其他行。
2. 逐卡核价格、数量、运费、到货与权利；字段一致不等于feed可上传、图片获准、库存真实或政策合格。不输出未验证的官方上传schema。
3. 按来源/用途/渠道/时点/期限/撤回/抑制列许可账。旧同意不覆盖后续撤回，服务许可不扩成推广；跨渠道计划与真实发送分开，无同步证据保持unknown，不执行删除或发送。
4. 迁移保存文档与实际平台基线的差别，明确只改哪项、保留什么、各市场意愿/授权/实际花费、观察点、容量/投诉停线与恢复owner。没有实际平台状态就不承诺线上可回滚。
5. 输出完整关系审阅、许可抑制/压力矩阵、逐市场草稿、责任/审批/退出交接和一个优先动作。草稿PAUSED且不存在未发布；所有真实动作需另授权。

[F4输入](payload__候选正文__Facebook广告运营Skill__meta-facebook-ads-operations__examples__f4__INPUT.md)及[输出](payload__候选正文__Facebook广告运营Skill__meta-facebook-ads-operations__examples__f4__OUTPUT.md)仅为合成应用；两市场/标签/期限不是当前平台或法律要求。要当前实施字段/法律结论但无证据时，停止该判断并列精确缺口，不把整份交付变空表。

## 人工搭建交接

广告准备完成时交一份可读、可复制但尚未在平台创建的具名版本，按当次所需而非空模板组织：

|交接件|必须交出的本轮内容|缺证只停什么|
|---|---|---|
|事实与素材账|商品/Offer、市场语言、版本/来源位置、素材编号/概念/变体、阅读与商用权、supplied_fact或假设分层|缺某主张就撤该主张；有据稿件仍交|
|三层计划|各Campaign任务、各Ad Set共同约束/受众路径/预算归属、各Ad素材与本地父关系；有据的目标/事件/版位候选及取舍|当前选项/资格未核就停对应搭建设置，不伪造账号ID或放弃业务层方案|
|可用广告与制作brief|逐Ad完整正文/标题/CTA、具体画面/镜头/版式与证据、素材版本及允许变换、页面承接|缺原片只停视觉/声音验收；制作未完成诚实标未完成|
|资源与URL|当次周期/币种、累计计划/成本/储备/损失、逐Ad字典与完整URL及工具结果|缺经济输入不猜0/均值；URL失败仅暂停该条链接交接|
|人工核对清单|就绪项、待核字段与证据、具名责任角色/未指定人、复议点/停止/恢复；真实操作由独立有权流程承担|不把“人审”当完成证据；关键待核未闭合不称可直接发布|

商品承诺、素材表达和目的页须逐广告一致；已观察的来源陈述、策略建议、平台实际配置和执行许可分别表述。按[结构](payload__候选正文__Facebook广告运营Skill__meta-facebook-ads-operations__references__meta-ad-structure-and-draft.md)保留M2、budget_owner_level、未创建/未发布与实际交付UNKNOWN。合成验证标工程/行为检查，不冒真实客户反馈或收益。

跟进时引用前版对象，记录改变原因；先交本次完整受影响稿件与URL，再说明保留/暂缓及恢复条件。撤回证据即撤相应主张/素材，不自动把旧URL结果搬到新版。需要最终汇总时合并全部仍有效稿件，不能让接收人拼多个历史答案。

## 人工审阅交接

当用户要创建/变更合同，先完成有据的中文报告与可用草稿，再按[入口输出合同](payload__候选正文__Facebook广告运营Skill__meta-facebook-ads-operations__METHOD.md#输出合同)给完整精简摘要。具体证据及既有类别回接正文结论；未知配置保留 UNKNOWN，对应补证检查标 NEEDS_RESEARCH，真实动作停在 HUMAN_GATE_REQUIRED。摘要不得换字段名、丢条件或用全空模板代替本次内容。

交给人工审阅的内容包含本地计划与版本、待核事项、拟动作及对象、负责人与尚未指定的审批人、预算口径/授权边界、停止/回滚及未创建未发布声明。预算归属按[结构](payload__候选正文__Facebook广告运营Skill__meta-facebook-ads-operations__references__meta-ad-structure-and-draft.md)使用准确的 `budget_owner_level`，建议层与实际事实分开；不把“运营执行”能力名称当作真实执行器已经接通。 公司能力owner与有权业务审批人分别识别，审批依据缺失则UNKNOWN；角色、使用者上级门禁和不可升级L0的边界统一见[权限](payload__候选正文__Facebook广告运营Skill__meta-facebook-ads-operations__references__permissions-and-live-gates.md)。

按[离线交接语义核对](payload__候选正文__Facebook广告运营Skill__meta-facebook-ads-operations__references__meta-ad-structure-and-draft.md#离线交接语义核对)逐项说明映射、明确继承或有理由排除，并保留父子意图与引用核对。质量、授权、未创建/未发布是本地控制信息，不是 Meta 参数。接收方无法保留合同或出现语义冲突时，只停止机器直接交接、列出不兼容项，保留可读计划；不补默认值、不写适配器、不操作账户。

## 不升级的边界

两个实例是同一生产者先锁输入再按既有规则产出，非独立新手、真实项目或非官方方法交叉验证。这里增加的是可调用的组织方式，不新增经营公式、许可法则或固定素材测试配方。来源/权利仍见[限制](payload__候选正文__Facebook广告运营Skill__meta-facebook-ads-operations__provenance__LIMITATIONS.md)。
