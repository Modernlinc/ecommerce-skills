# Facebook 广告｜从这里开始

本包帮助你把已准入的商品、素材和目标整理成可供人工搭建的广告准备方案：具名三层草稿、完整文案、静态UTM、首批资源与后续条件。无数据的一般概念解释也可使用；不执行真实投放。

## 怎样开始

让支持本地文件读取的AI读取[方法入口](payload__候选正文__Facebook广告运营Skill__meta-facebook-ads-operations__METHOD.md)，然后先说明这次要解决的问题、材料来源/用途/非敏感性质与精确范围，通过[读前准入](payload__候选正文__Facebook广告运营Skill__meta-facebook-ads-operations__references__permissions-and-live-gates.md#打开资料前的准入)后再提供内容。无需先填完整问卷。

先看一个完整例子：[从素材说明到第一轮方案](payload__候选正文__Facebook广告运营Skill__meta-facebook-ads-operations__knowledge__2026-10-19-first-round-and-utm-walkthrough.md)。它包含两条文案、完整虚构URL、预算核对和条件变化，不是实盘效果案例。

- 只需链接标签与检查：读[静态UTM方法](payload__候选正文__Facebook广告运营Skill__meta-facebook-ads-operations__references__tracking-parameters-and-url-checks.md)。
- 不知道先测什么或怎样选人群：读[阶段、受众与学习资源](payload__候选正文__Facebook广告运营Skill__meta-facebook-ads-operations__references__stage-audience-resource-playbook.md)。
- 成果检查：先核商品/版本、取舍与完整稿件，再核主要未知、损失与停止位置；不是只看是否生成文件。
