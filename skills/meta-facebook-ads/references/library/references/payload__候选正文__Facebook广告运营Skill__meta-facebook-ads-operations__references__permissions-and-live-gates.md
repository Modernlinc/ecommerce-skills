# 权限与真实操作门禁

## 当前能力上限

本 Skill 能力上限为 L0_OFFLINE。本版允许一般解释、安全合成资料，以及通过读前准入的公开或使用者自有非敏感商品/Offer、素材、资源和获准汇总经营数字；客户/订单/事件明细及脱敏件、可重识别汇总、账号材料或其他敏感资料须在读取前暂停，并取得使用方有权数据责任人对具体材料与用途的确认；还须满足当前宿主上级规定的具名确认和本包能力边界。该确认不自动允许本L0包处理已排除的数据或接入账户。可交教学、审计、计划、诊断、实验设计和未创建的声明式广告草稿，供人工审阅搭建；不是平台执行器。版本或质检状态不扩大真实操作权限。

### 打开资料前的准入

先根据已给元信息核对：具名来源/文件或URL范围、使用者的所有权或可用依据、本次用途、是否含敏感类型。已明确的声明复用，不反复要求填表；范围或性质未知则先问，不通过预览、OCR、解压或全盘搜索来确认敏感性。混合文件整件停读；可继续独立已准入资料，不要求先上传敏感原件再脱敏。误显敏感内容立即停读，不复述或写入交付件。

可读取：原创安全材料；公开商品/政策的非敏感事实；使用者明确自有、有权用于本次任务且不含敏感信息的商品/Offer、素材或说明、市场/目标/资源；明确获准口径/用途的非敏感汇总经营数字。可由元信息明确独立的公共商品页读事实，但公开个人评价/联系方式、客户记录不因公开自动准入；出现混合或访问控制即停止对应读取，不绕过限制。阅读许可与素材广告商用权、平台实施资格分别记录。

这些类别必须先停止读取，并核实使用方有权数据责任人对具名范围、用途和必要性的确认，同时满足当前宿主上级具名确认及本包能力边界。涉及类别：真实客户原话、名单、订单/事件明细（包括脱敏件）、可能重识别的小样本汇总、账号导出/截图、银行/支付/合同隐私、保密底价或工程资料。账号/口令/密钥不索取。本包不因“自有”“已脱敏”或“经理同意”自动放行这些类别；具体确认后仍须核是否超出本包能力，不能据此登录平台。

种子/暖池/老客仅接收获准非识别性汇总说明及用途许可状态，不收名单、不推定种子合格或当前账号可选。预算分析只使用已获准讨论额度/成本口径；给出条件建议不改变真实预算，也不授予花费权。未提供实际执行许可不阻断有用的离线文案和方案。

准入结论指向具体材料/用途与声明位置，不把授权文本混作商品事实。未通过读前确认的具体项为HUMAN_GATE_REQUIRED；普通缺失规格为UNKNOWN/NEEDS_RESEARCH；已知矛盾为NEEDS_FIX，三者不混用。

- 数据责任人：有权说明具体资料来源、可用依据、范围、用途与敏感性；资料确认不等于广告/预算审批，也不覆盖本包排除的数据。
- 业务审批人：有权批准具体业务计划、素材、资源与版本；业务批准不等于平台技术权限，不自动产生花费或发布授权。
- 技术权限责任人：在另行获准的独立流程中核验应用、token主体、资产范围和最小权限；本L0包不索取或检查凭证。技术可访问不等于业务获批。
- 外部执行者：必须另有执行能力和对具名对象/动作的授权，按批准版本操作并留回执；当前离线Skill不是该执行者。
- 公司能力owner只管理本产品能力与发布范围，不默认代替买方以上角色。只有真实、可定位的授权才能兼任；未知即明确未知。安全合成/非敏感离线准备不要求先填写或取得这些真实角色。

本L0包仅整理待审材料，不执行真实账户/支出/发布。上述角色的任何批准均不能把本包升级成真实执行器；如需外部执行，转交另有能力与具体权限的执行流程，服从当前会话上级授权规则。

若当前宿主或项目上级规则要求由具名人员（例如本项目的使用者）确认敏感操作，仍必须由该人员按原规则单独确认；上述通用角色不能替代、转移或放宽该门禁。下列动作均不在本L0包执行范围；被请求时对具体动作输出`HUMAN_GATE_REQUIRED`并停止，不影响获准的安全离线部分：

- 登录、验证码、OAuth、token、secret、API key；
- 真实 Page、Business Portfolio／Business Manager、Ad Account 或 Marketing API 访问；
- 未单独获准的真实客户、事件、订单、受众明细及脱敏件、可重识别汇总或其他敏感资料读取；合同内非敏感公开/自有资料不在此禁读项；
- Page／Business／Ad Account 权限、人员、资产归属或恢复设置变化；
- 预算、竞价、Campaign、Ad Set、Ad、Pixel、CAPI 或事件写入；
- 发布、付款、Production、来源删除或全局安装。

授权一个动作不自动授权其他动作；只可继续本地安全工作。

## 权限分层

Page access、task access、full control 及 Business／Ad Account 角色不能互相替代。2026-09-03 控制器通过官方搜索快照确认了 Page 权限风险差异；2026-09-04 公开页面再刷新被登录墙阻断。任何当前字段、可用角色、资格和实际权限仍必须以当前官方页面或已授权账户回读为准。

只要无法确认主体、资产 owner、付款责任、恢复责任、最小角色和审批人，就保持 `UNKNOWN`，不建议共享主凭证、默认管理员、借用主体或绕过限制。

## 广告与自然运营负向路由

以下不属于本 Skill：

- Facebook Page 内容策略、日历、排期与自然发帖；
- 评论、私信、群组、社区治理和声誉管理；
- Facebook 自然增长、粉丝增长或完整主页运营；
- Instagram 自然内容、达人、社群、私信、账号增长或完整运营。

遇到这些任务，输出 `NEEDS_RESEARCH` 与 `route_out: true`，转交相应社媒／内容／社区 Skill。若同一请求同时含广告和自然运营，只处理广告部分，并明确拆分边界。
