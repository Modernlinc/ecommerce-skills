# 测试、诊断与停止

## 零数据路径

按[从零素材到初始方案](payload__候选正文__Facebook广告运营Skill__meta-facebook-ads-operations__references__meta-ad-structure-and-draft.md)区分本次缺少的观察，完成素材台账、概念/变体、主要问题、合并/拆分理由、预算归属候选、具名三层草案及首批/暂缓安排；不是只审查用户已经选好的结构。

以本任务给出的商品、Offer、页面、市场、币种、时区、资源和损失约束为依据；未提供的未来表现仍 UNKNOWN，不把零数据当测量错误。计划可为 DRAFT，并交出有条件的具体值，不需要先取得真实账户数据。

预先写明两层检查：
1. 本轮离线检查：内容依据和主张一致、素材映射完整、父子关系符合拟议意图、预算累计守恒、文案与页面承接；何时完成、失败改哪一项、原版本怎样保留。
2. 后续效果观察：实际交付/花费、事件与订单口径、可比窗口、报告与退款成熟、最大等待/损失、停止和回滚。没有延迟或基准率就不硬编有效样本量/固定天数，先完成第一层并具名待补。未来要实施必须另经权限与当前事实核验。

材料只支持内容/准备取舍时，不要求定赢家；新增信息只更新依赖判断。一次主要验证问题不限制同轮完成相关离线步骤，也不限制在相同问题下准备有理由的多个候选。首批数量与时钟由任务决定，不写成固定结构或配方；单变量仍不保证因果。

## 已有数据诊断顺序

1. **测量完整性**：事件、值、币种、去重、窗口、数据延迟。
2. **资格与交付**：对象状态、审核／限制证据、实际花费、实际版位和实际受众分配。
3. **创意到页面连续性**：主张、点击意图、加载、同意、页面首屏、Offer 与结账。
4. **受众与 placements**：计划约束、自动扩展、重叠、频次和实际分配。
5. **预算与竞价**：预算归属、损失上限、变更时间、学习／交付变化；不采用通用阈值。
6. **样本与因果**：成熟期、唯一变量、同期变更、外部因素和分配/比较单位；按下述边界报告观察差异。

找到最早可信断点后，明确一个优先的最小可逆验证动作；可继续完成不依赖该缺证的文案、整理和交接。缺少证据时使用 NEEDS_RESEARCH 或 UNKNOWN，不跨级猜原因；这条诊断优先规则不是每轮只交一个动作、取消后续任务或停止全部离线产出的限制。

## 素材表现与疲劳候选分路

以下为公司条件诊断整理，不是已验证的疲劳识别器。

疲劳只作为可反证候选，不由频次升高或CTR下降直接确诊。先对齐素材/文案版本、指标分子分母、归因与成熟窗口、实际人群/版位暴露、同期竞拍/预算及页面Offer变更。缺可比性时保留原列描述，列最小缺证，不混合估计素材衰减。

若仅总体表现变差，而同口径人群/版位等可比暴露分层的表现没有相应恶化（不是仅指曝光量稳定），或变化与交付构成/页面/归因调整重合，优先保留这些替代解释，削弱“素材自身疲劳”的解释；总体下降与构成变化并不证明没有疲劳，分层也不是随机证据，对比条件不完整则保持UNKNOWN。若同素材在可比条件下持续衰减且竞争解释仍未证实，才列疲劳候选，不能称因果或排除所有混杂。若CTR稳定而页面到达/转化恶化，先核页面与测量，不据此要求重做Hook。

输出候选解释、支持/反对/缺失证据、一个最小离线核对动作及brief影响。交付构成未核清时，保留素材基线并先查同版本/同口径分层与变更记录；已有承诺/权利错误可独立修正，不把该安全修正当疲劳实验。只有有据时才提带主变量、停止条件的素材候选，未知不补阈值，causal_claim_allowed=false。

### 留存异常到素材片段的最小核对

仅在输入包含视频留存/播放曲线且需要定位改稿时使用。先确认指标定义、分母、曲线所对应的素材版本、报告窗口和实际交付；只把异常位置当作待核片段，不把下降、平段或回升直接解释为内容原因。曲线实验性、数值冲突或版本不清时，保留异常与UNKNOWN，不补阈值。

取得有权使用的同版原素材后，连同该位置前后语义观察画面、口播、字幕、承诺/证明/CTA的变化；记录“位置与内容 → 支持/反对/缺失证据 → 一项信息修改候选”。没有原素材或无法匹配版本，停止片段级原因判断，仅提出所需实物与核对目的；可继续完成独立的文字事实/权利审阅。

新候选只改一个主要信息变量，沿用真实商品、Offer和已有损失/授权门，不把拼接高hook与低CPA素材当成有效性证明。曲线检查、文本改稿和付费验证分开；当前L0仍causal_claim_allowed=false。

来源与成熟度：2026-10-08 Ben长教程文字/provider分析与既有诊断门融合出的条件化方法候选，未见原像素或真实效果。[融合证据与适用限制](payload__候选正文__Facebook广告运营Skill__meta-facebook-ads-operations__provenance__SOURCE_NOTES.md#long-video-20261008)。

## 因果结论的本版边界与未来证据

当前 `L0_OFFLINE` 的 `causal_claim_allowed` 始终为 `false`。本版允许实验规划、观察差异和明确归于来源的研究结论摘要，不自行签发因果效果，也不因清单填满、平台实验资格或实际交付可见而改为 true。

单变量仍用于控制变更，但不是因果充分条件。两个创意各花1,000、分别100/40单、CPA10/25，即使数据成熟且实际交付已知，若算法分别多送高/低倾向人群，差异仍不能归因为创意效果。

未来提出独立个案审查至少需说明：处理/对照、目标人群、主要结果与估计目标；分配单位及分析/比较单位；随机分配证据或可辩护反事实及其可检查假设；实际实施、不依从、交叉暴露和群间干扰；样本不确定性、成熟窗口及预设停止/提前查看处理。单位不一致须解释聚类/依赖，不能只比较平台选择后的点击者/转化者而忽略原分配。

这些是证据要求，不是当前自动准入条件。只有设计、存在污染、单位差异未处理或只有观察结果时，继续报告限制及最小补证动作；即使提供完整离线结果，本版仍保持 false。来源研究只在其研究范围内署名概述，不升级为当前任务效果。未来要改变本版能力边界，须另提 `REASONING_ESCALATION_REQUEST` 由总控审定证据、范围和责任；本轮不新增运行状态或统计引擎。

## 自动交付污染

当 Advantage+、自动版位、受众扩展、动态组合或预算重分配改变实际暴露时：

- 保存计划设置、实际分配、时间戳和变更记录；
- 不把广告对象名称、计划受众或上传素材数当作实际暴露；
- 无实际交付证据时不能宣布某个受众、版位或素材胜出；
- 输出 `NEEDS_RESEARCH`，最小动作为补齐 breakdown／交付回读或设计更干净的对照；
- 不为获得“干净数据”而直接修改真实账户。

## 预算与停止

`META-METHOD-BUDGET-01` 不采用固定百分比、固定 CPA 倍数、固定天数或固定事件数。预算草稿应记录：

- `budget_owner_level`
- `maximum_affordable_test_loss`
- `expected_goal_action_cost`（证据不足则 `UNKNOWN`）
- `conversion_delay`
- `parallel_hypotheses_count`
- `measurement_readiness`
- `observation_plan`
- `stop_conditions`

经营计算与贡献利润使用 [业务指标与单位经济](payload__候选正文__Facebook广告运营Skill__meta-facebook-ads-operations__references__business-math-and-unit-economics.md)；输入缺失、分母为 0 或 cohort/窗口不可比时保持 `UNKNOWN`。情景结果不授权花费。

立即停止或降级的条件：测量完整性失败、最大可承受损失触达、关键假设失效、业务容量／现金约束触达、样本未成熟却被要求定赢家、实际交付不可辨、素材权利或主张证据缺失、出现未授权真实操作。
