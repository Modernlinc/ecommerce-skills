# Facebook / Meta 广告

## 功能摘要

面对商品资料、素材想法和页面文字散落在不同位置的情况，先整理本次要表达的事实，再形成可供团队讨论的广告结构、文案与素材安排。公开演示让读者看到从输入到完整工作稿的过程，并明确页面缺项及尚未执行的动作，帮助减少广告与商品承诺不一致的交接错误。

适合：广告协作人员、内容策划与投放学习者。

## 输入

获准的合成商品事实、页面文字、可制作素材与本次任务。本公开版只使用原创合成材料；真实资料不在本演示范围。

## 输出

结构草案、两条广告文案、素材 brief、承接问题和未决项。交付为可阅读、可检查的文字，不暗示已完成平台执行。

## 演示步骤

1. 读取本项[合成输入](examples/input.md)，先确认任务和已给事实。
2. 分清用户目标、明确事实及未知；缺失事实保持未知。
3. 只在本页公开范围内组织工作稿；不加载付费方法或私有材料。
4. 交出完整请求结果，引用输入中能支持它的事实。
5. 标出限制、待补信息与尚未执行的动作；请求超出范围时停在文字交接。
6. 完成首答后再阅读[示例输出](examples/output.md)比较；参考答案不代表唯一正确表达或独立盲测。

## 限制说明

只展示离线广告准备；不连接 Meta API、不自动投流、不生成真实预算批准或收益预测。UTM 若提供，也只是待核对的命名草案。

本公开版不是完整付费 Skill，不包含其专业方法、私有references或运行模块。示例不证明商业效果；需要真实账户写入时另行确认权限与实施条件。不要编造缺失事实或把草稿称为已发送、已上线、已投放。
