# Shopify 独立站

## 功能摘要

让独立站访客先看清商品是什么、适合怎样的使用场景、有哪些可选规格，再决定下一步。公开示例将给定商品事实组织成完整页面文字，处理价格、规格、出库与运输的区别，并把尚未确认的费用留给编辑补证，避免用空泛卖点代替可检查的信息。

适合：独立站商家和商品页编辑。

## 输入

合成规格、供货和费用条件、原页面问题。本公开版只使用原创合成材料；真实资料不在本演示范围。

## 输出

商品页全文、选项与行动句、FAQ和待补项。交付为可阅读、可检查的文字，不暗示已完成平台执行。

## 演示步骤

1. 打开[单文件试阅](examples/demo.md)，将该文件整体复制或上传给能读取Markdown的AI助手；本页无需再复制。
2. 按文件里的任务处理合成输入，不登录、不安装依赖，也不读取参考输出代答。
3. 保存自己的完整结果，按试阅文件的交付清单与逐项核对点检查。
4. 再看[编辑参考输出](examples/output.md)比较事实、交付形式和未知项处理；不要求逐字相同。
5. 若缺输入，指出具体缺项并停在文字交接。参考输出不是AI独立运行或完整商业Skill验收的证明。
