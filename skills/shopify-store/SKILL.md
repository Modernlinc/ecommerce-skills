# Shopify 独立站

## 功能摘要

将商品事实整理为可交编辑的完整商品页。方法、模板、相关脚本和示例均随本目录提供，免费使用，许可见 [LICENSE](LICENSE)。

## 输入

- 尺寸、颜色、价格和单件数量
- 现货与出库准备时间
- 有问题的原首屏和未知事实

先确认本次任务、对象、目标和材料使用权限；缺失事实保留未知，不从示例补造用户事实。

## 工作流程

1. **先读取 [完整方法入口](references/library/payload/shopify-dtc-review-candidate/METHOD.md)**，再按它的导航读取本次任务所需的参考、合同和模板。所有路径以所在文件的目录为准；引用前的 `@` 与普通相对路径同义。本目录外没有运行所必需的项目资料。
2. 使用用户本次提供或明确授权的材料，按方法完成判断和所请求的完整成果，不只复述流程或列出工具。
3. 将商品/业务事实、来源观点、假设和未知分开。需要当前政策、价格或资格时核对适用官方资料；无法核实则保留待核。
4. 交付前核对成果中的主张、单位、日期、范围和引用是否匹配输入。跟进时更新受影响的完整稿，保留仍有效的内容。
5. 需要脚本时先检查运行环境、输入和输出位置，再运行该脚本；未运行不能报告执行成功。真实账户、广告支出、发布、支付或库存操作不由安装授权。

## 输出

- 英文商品页首屏与选项文字
- 详情、出库/运输区和FAQ
- 中文编辑交接与待补项

同时交代关键依据、未确认事项及下一步；不要求使用者拼接互相冲突的旧稿。
