# 十八项公开功能卡与试阅

[产品首页](../README.md) · [材料与成果目录](../docs/skill-catalog.md) · [开始试阅](../docs/getting-started.md)

每项目录均有：

|文件|用途|
|---|---|
|SKILL.md|任务、输入要求、输出、演示和边界|
|examples/demo.md|可整体复制或上传的单文件试阅，不含参考答案|
|examples/input.md|独立合成题设|
|examples/output.md|编辑编写的完整参考工作稿|
|assets/screenshots/README.md|演示介质说明；本版无平台截图或成片|

数据核算案例另外提供examples/data/下的五份CSV及字段说明。所有案例的题设彼此独立；相同示例品牌不表示可互借价格或规格。

SKILL.md元信息中的name与目录匹配，description用于发现任务，metadata记录展示名、public-demo状态与公开版本。使用这种文件结构不代表所有客户端已经完成安装实测；具体范围见[兼容说明](../docs/compatibility.md)。

[机器可读目录](../catalog.json)与人类目录描述同一公开资料；没有加载隐藏私有依赖。
