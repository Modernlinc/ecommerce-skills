# 制作委托与检查指导（不执行软件）

本文件把M1—M4转为执行方的文字需求与检查项。先读SKILL和GUIDE；以下观察、编辑、导出、播放及工程检查均指另行获准的未来执行方，不是本轮助手执行命令。本轮不启动软件、操作工程或生成媒体；缺素材写待核，不自行调用工具补证。

## 1. 说明委托与责任

区分修图、静态素材剪辑、生成式视频，列期望交件及未授权项。brief不是媒体，PNG不是PSD，MP4不是可编辑工程，二维推拉不是真实运动/新视角。工具能力、许可、费用和工程保护由未来执行方另行确认，不由本指导预授。

## 2. 母版与不可变项（M1）

列真实SKU/原创合成身份、母版定位、权利、可见面、轮廓、部件数、图形/字样、颜色/材质、视角、光向和接触。未见像素标待观察，不把口述当目视。明确保护区、允许变化和unknown；真实商品未见面、结构、功能不能生成后当真；合成不冒充商品/客户案例。

## 3. 修图委托与回件检查（M2）

写允许变化、预期及保护项。要求执行方先记录原图，再比接触阴影、远投影、光向、材质和结构；原图无缺陷，不把换背景称修复。无材质依据不加镜像反射，不采用固定164px、28%或Multiply通用配方。

回件逐项核轮廓/面数、部件、图形/字样、颜色、边缘和接触。平面结果只是版本回退，不保证PSD；要求区域外像素零差而路线无受控掩模/像素核验能力时停止。单个哑光纸盒不外推透明/镜面/多光源。

## 4. 分镜与剪辑交接（M3—M4）

文字列每段输入定位、画面变化、时长、保护项及未知，静态裁切与生成运动分开。要求先核静帧，再核分格、放大、修复/调色后的身份关系；重绘不称无损。结构/图形/数量/材质漂移或关键unknown时停受影响段，不用黑边、颗粒或高分辨率标签掩盖。

仅实际有具体失败且在另行批准的次数/费用内才局部修正；未失败不强制第二轮，不无限生成。这是未来执行者的停止条件，不是本入口已跑通操作。

## 5. 未来交件证据

委托说明所需文件、尺寸/时长/帧率/音轨、版本对应、前后对比、完整播放和工程可编辑证据。首中尾截图不代替连续观看，文件存在/可开不等于通过，工程文件不等于独立再导入；未验就记unknown。

未来执行方保留原件/失败证据，遇漂移或覆盖/许可/费用/用户工程冲突即停；自检不代独立验收、客户接收或效果。本轮只检查文字要求是否明确，不产出MP4/DRP，不因此阻断本指导范围的适用质检与封装。
