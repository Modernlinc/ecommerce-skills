# Google SEO 证据与安全边界

## 1. 四层结论

任何判断都标明层级：

1. `OBSERVED`：在指定 URL、文件、导出、代码或官方页面直接看到的事实。
2. `INFERENCE`：由观察提出的解释，必须写替代原因和置信度。
3. `HYPOTHESIS`：待验证的增长、排名或业务假设。
4. `PLANNED`：建议做的动作；不能写成已经执行。

第三方工具的 search volume、KD、DR、流量、反链、AI citation 和收入估算都是候选信号，不是 Google 事实、第一方结果或因果证明。

## 2. 最小证据合同

每个问题记录：

`对象｜日期/时区｜市场/语言｜观察入口｜实际值｜缺失字段｜变更日志｜可能原因｜替代原因｜下一证据｜成功判据｜停止点`

常见证据优先级：

`当前官方事实 → 获授权一方数据/页面与日志 → 可复现实验 → 多来源专业方法 → 第三方估算/课程观点`

高层证据可以纠正低层来源。一次案例不能升级为通用规则。

## 3. 权限和数据

需要 Search Console、GA4、日志、CMS、Business Profile 或客户业务数据时，先生成：

`delegated_evidence_request = 目标｜授权提供人｜资产代号｜时间窗/时区｜脱敏字段｜明确排除的 PII/密钥｜导出格式｜生成时间/哈希｜安全交付｜回读负责人｜拿不到时的 UNKNOWN/停止`

姓名、邮箱、电话、地址、客户 ID、完整查询自由文本、Cookie/标识符、API key、OAuth、session 和日志中的敏感参数只在必要且明确获授权时处理；默认请求聚合或脱敏数据。

任何登录、真实账号读取、客户数据处理、API/CMS/Production 写入、发布、域名/DNS、迁移、删除、支付或预算动作都是 `HUMAN_GATE_REQUIRED`。

## 4. 内容、AI 与权利

页面 brief 至少记录：

`真实作者/责任人｜目标任务｜一方经验/证据｜来源与引用权｜事实核验日｜素材权利｜AI 使用范围｜人工审阅｜更新/撤回｜风险领域审查`

拒绝：伪造使用体验、作者、评论、门店、资质、数据、测试、案例、最佳榜单或法律/医疗/金融结论；去水印、翻转、改背景不创造权利。

自动化发布前必须闭合：来源、版权/许可、隐私/ToS、事实、重复检测、样本 QA、失败重试、日志、批准与回滚。缺一则只能做离线草稿或研究。

## 5. 程序化页面门

程序化并不等于垃圾；准入必须同时满足：

- 每个 URL 对应真实且有差异的用户任务或事实，而不是只替换关键词/城市名；
- 数据来源、更新时间、缺失/冲突和删除规则明确；
- 模板之外有足够的独特价值、可用功能或决策信息；
- URL、canonical、分页/筛选、内链、sitemap 与重复策略清楚；
- 上线前分层抽样，按新旧/高低流量/模板类型测试；
- 有抓取、渲染、索引、质量、业务结果、成本和回滚监控；
- 先小批量，失败不继续扩张。

“有人搜索”或“竞品有页面”不满足准入。

## 6. 链接与声誉

允许候选：真正有用的工具/数据/研究、记者或行业媒体关系、合作伙伴引用、品牌提及更正、相关 broken-link reclamation、需要披露的合法赞助。

拒绝：PBN、隐藏网络足迹、链接租售、付费 dofollow、自动评论、批量 Web 2.0/Cloud/Map/Brand stack、平台账号只为留链接、互换/租用榜单、虚假新闻稿、评论/点击/路线操纵。

外联草稿记录：

`真实关系/受众价值｜目标页面｜为何相关｜权利/披露｜编辑自主权｜是否付费｜rel 资格｜不承诺 dofollow/排名｜停止条件`

## 7. 因果与报告

变更前冻结：页面/查询/国家/设备、技术状态、索引状态、发布内容、外链/PR、广告活动、季节性、竞争、算法/平台事件、GSC/GA4/业务指标和时间窗。

一次只检验一个主要假设，写明保持不变项、完整观察窗、最大损失和回滚。无法隔离时只能写“与变化同时发生”或“可能原因”。

报告不得把以下状态混写：

- 已提交 sitemap / 请求收录；
- Google 已抓取 / 已索引；
- 已展示 / 已点击；
- 已发生 key event / Ads conversion；
- 已产生合格线索、成交、收入或贡献利润；
- 客户/人工验收。

## 8. 普通运行状态

`DRAFT｜NEEDS_FIX｜NEEDS_RESEARCH｜UNKNOWN｜HUMAN_GATE_REQUIRED`

这些状态描述当前对象和下一步，不是终验结论。总控的 `NOT_READY`、`REVISE`、`REJECT`、`PASS_INTERNAL`、`PASS_FOR_DEFINED_SCOPE`、`BLOCKED_EXTERNAL_EVIDENCE` 只在独立终验流程使用。
