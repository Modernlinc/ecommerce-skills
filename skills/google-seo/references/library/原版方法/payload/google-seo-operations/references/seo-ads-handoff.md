# Google SEO—Google Ads 交接合同

SEO 与 Google Ads 是独立能力。融合发生在业务、查询、页面、转化与实验交接层，不把两个 Skill 合成一个模糊归因系统。

## 1. 可以共享

| 共享对象 | 最小字段 | 用途 |
|---|---|---|
| 业务真值 | 市场、语言、Offer、受众、主要结果、价值/成本、停止线 | 让自然与付费服务同一经营目标 |
| 查询词典 | 查询、意图、品牌/非品牌、市场/语言、证据来源、日期 | 建立共同需求地图 |
| 页面事实 | URL、页面类型、承诺、证据、资格、主要 CTA、技术状态 | 检查搜索意图—广告—页面连续性 |
| 转化定义 | 事件、业务含义、去重、价值、币种、时区、数据源 | 避免 clicks/key events/conversions/成交混写 |
| 变更日志 | 日期、渠道、对象、变量、批准人、版本、回滚 | 防止同期变化被误判为单一因果 |
| 实验合同 | 假设、基线、主变量、保持不变、观察窗、最大损失、停止 | 让两边都能复盘但各自裁决 |

## 2. 必须分开

| SEO | Google Ads |
|---|---|
| 抓取、渲染、索引、自然呈现、自然 query/page 表现 | Campaign/Ad Group/Ad、Search term、Feed/商品资格、预算/竞价、广告政策 |
| GSC clicks/impressions/CTR/position | Ads cost/click/conversion/value/attribution |
| 内容、架构、技术、Local、自然权威与站点生命周期 | 付费流量、广告资产、Merchant、PMax、否定词与出价 |
| 自然排名/流量假设 | 广告增量/获客成本/利润假设 |

广告花费或广告访问不会提升自然呈现；自然排名改善也不证明广告合规、增量或利润。

## 3. SEO → Ads 交接

输出：

`市场/语言｜自然查询集｜页面/内容证据｜当前自然可见性｜缺失页面任务｜不能支持的承诺｜技术/资格风险｜可测试假设｜不可作因果的边界`

Ads 可以把这些作为关键词、搜索词、广告承诺和页面测试输入，但需要独立检查预算、转化、政策、账户与增量。

## 4. Ads → SEO 交接

输出：

`市场/语言｜搜索词（脱敏/聚合）｜广告承诺｜落地页｜转化定义｜样本/成本｜观察窗｜同期变化｜可供 SEO 验证的需求假设｜不得外推项`

SEO 可以用来发现意图、词汇、页面摩擦与内容缺口，但不能把广告点击、CTR、停留、转化或流量直接写成自然排名因素。

## 5. 共同实验门

1. 先定义业务结果和统一时间口径。
2. 分开自然与付费样本、品牌与非品牌、市场/语言和页面版本。
3. 一次只改变一个主要变量；若 SEO 与 Ads 同时变更，结论降级为相关观察。
4. 两套平台指标分别报告，再回接相同业务结果；不能相加去重未知的 conversion。
5. 真实账户、预算、广告发布、客户数据、CMS/Production 页面修改均需各自授权。

## 6. 冲突处理

- Ads 想测试的新承诺没有页面或事实支持：停止广告草稿上线，先补真实页面证据。
- SEO 页面排名有量但业务价值差：不要仅因自然流量保留；评估任务、转化、成本和生命周期。
- Ads 搜索词有转化但自然无表现：形成 SEO 机会假设，不承诺排名或复制广告页面。
- 自然内容吸引信息流量但 Ads 成本高：区分教育、品牌和商业意图，不用一个页面/指标强行统一。
- 两边结论冲突：回到来源、定义、时间窗、去重与变更日志；无法闭合保持 `UNKNOWN`。
