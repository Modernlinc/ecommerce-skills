# 国际化关系审阅与修订草稿

用于同一页面任务的语言/地区版本审阅和离线修订；不同商品或不同意图不因语言不同就强行归组。依据Google localized-versions官方正文，观察2026-10-10，更新2026-09-21；当前适用范围与未证事项见[本轮范围](../../../../03_能力与来源.md)。

**输入和证据：**收集版本URL、目标语言/地区、内容对应关系、现有标记及其所在HTML/响应头/sitemap、时间与允许动作。明确哪些页面实际提供，哪些未观察。页面正文、canonical、索引状态和语言关系分开记录；不从hreflang推断这些状态或业务资格。

**代码与可选兜底：**语言用ISO 639-1；可选地区用正式分配的ISO 3166-1 Alpha 2，不能仅填地区，标识大小写不敏感。脚本可用ISO 15924，位于可选地区之前。形式不等于值合法，未证值记UNKNOWN。x-default可选，用于未匹配用户的真实兜底页，不附语言码。

**关系与载体：**HTML、HTTP头、sitemap是三种等价入口，不要求同时建设。默认各版本列含自身的一致集合，URL用绝对地址，逐对查返回；难以维护全量时保留互链部分，新语种尤其应与原始/主导语种双向连接。HTML的rel=alternate、hreflang、href放有效head，勿与media合并；HTTP Link项用尖括号URL及rel=alternate、hreflang，逗号分隔，各版本含自身且集合一致；sitemap声明xhtml命名空间为http://www.w3.org/1999/xhtml，每URL有loc及含自身全部版本的xhtml:link，子项同样含rel=alternate、hreflang和href。托管目录覆盖范围另核，跨站资格未知不签提交合格。无法证明载体、URL或内容对应关系时，仅停依赖它的生成结论，明确最小补证，不编造版本。

**实际成果：**列页面族与证据定位、已证错误/未观察关系、每个受影响对象的旧值→拟值（无旧值时给完整拟稿）、责任人和必要回退。输出真实输入对应的具体标记，不只交空表或“建议配置”。保护既有已证有效关系与无关字段；不顺手改canonical/noindex、URL架构、跳转、页面内容或线上配置。

**复核与停止：**先逐页/逐对核本地拟稿，再由获准负责人回读实际发布载体；Google处理与搜索结果另需其自身证据。未知页、字段冲突和资格缺证保持可定位的未知，不签整站正确或效果保证。真实账号、部署、抓取请求、客户数据等仍按全包权限门禁停止。

来源定位：同一官方页通用与HTML L149–172、部分缺失L154–156、HTTP头L199–217、sitemap L218–231、代码规则L290–310、排错L321–333。[Google localized-versions现行官方正文](https://developers.google.com/search/docs/specialty/international/localized-versions)；官方示例只证明文档示例存在，不冒充本方法已通过实例验证。
