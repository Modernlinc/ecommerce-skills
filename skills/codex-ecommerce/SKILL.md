# Codex 电商执行

## 功能摘要

运营改价或变更交付条件时，常见问题是主页面改了，FAQ和协作简报还留着旧信息。本演示用明确的原文与变更要求，交出多份完整新版文字及差异说明；读者能够直接检查哪些内容已同步、哪些事实保持原样，减少只得到零散修改建议后的重复整理。

适合：需要改稿和跨文件一致性检查的编辑。

## 输入

获准离线原文、明确变更及保持不变的事实。本公开版只使用原创合成材料；真实资料不在本演示范围。

## 输出

完整新版文件文字、改动说明与待核事实。交付为可阅读、可检查的文字，不暗示已完成平台执行。

## 演示步骤

1. 打开[单文件试阅](examples/demo.md)，将该文件整体复制或上传给能读取Markdown的AI助手；本页无需再复制。
2. 按文件里的任务处理合成输入，不登录、不安装依赖，也不读取参考输出代答。
3. 保存自己的完整结果，按试阅文件的交付清单与逐项核对点检查。
4. 再看[编辑参考输出](examples/output.md)比较事实、交付形式和未知项处理；不要求逐字相同。
5. 若缺输入，指出具体缺项并停在文字交接。参考输出不是AI独立运行或完整商业Skill验收的证明。

## 限制说明

演示只编辑给定文字，不写入任何店铺、数据库或真实后台；保存权限、运行环境和外部动作需要另行确认。

本公开版不是完整付费 Skill，不包含其专业方法、私有references或运行模块。示例不证明商业效果；需要真实账户写入时另行确认权限与实施条件。不要编造缺失事实或把草稿称为已发送、已上线、已投放。
