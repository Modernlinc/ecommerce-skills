# Codex 电商资料修订：使用说明

版本：0.5.0-s3-candidate.1。本版为S3局部修订候选，新增同任务后续的编辑基线、撤证及明确目标变化规则，尚待使用验证和总控审定。母本0.5.0-r2的2026-10-10限定独立终验为PASS_WITH_EXCEPTIONS（CODEX-SKILL-SCOPED-FINAL-20261010-01），绑定0.5.0-r2-candidate.1的5件冻结内容；旧验证仅复用于未改部分，不代表本候选已获同一裁决。旧两阶段只验证对话全文交付→获准保存与回读，未验证业务事实或目标变化后的接续。本候选尚未正式采用或公开发布。

## 从哪里开始

在能读取本地文件的 Codex 桌面会话中，指定本文件夹里的 [原版__payload__METHOD.md](原版__payload__METHOD.md)，并提供获准使用的资料。无需填写内部合同、寻找公司目录或安装额外程序。若会话无法读取该入口，可把入口和它指向的工作流作为任务资料提供；仍须以会话实际支持的能力为准。

准备完整原稿、商品/变体的可区分标识、原稿版本、确认材料，以及希望改什么、必须保留什么。推荐 UTF-8 Markdown/TXT；小型 CSV/JSON 可作事实表。扫描件、图片或复杂文档若无法可靠读取，应先取得可读正文，不能把残缺提取当完整原稿。只需提供本次必要的授权资料。

可复制的任务提示：

> 请使用我提供文件夹中的 原版__payload__METHOD.md，核对这份完整商品/页面原稿和确认材料，给出完整可编辑修订稿及变更说明。请保留我指定的未改内容，标明缺证处。原稿、确认材料、对象/版本、期望修改和保留范围如下：【填写实际内容或可读文件位置】。本次先在对话中交两份完整内容，不保存文件。

需要本地文件时，可在当前会话提出明确请求，例如：

> 请把本次修订稿和变更说明保存到【实际获准的新目录】的 REVISED.md、CHANGES.md；只新建，不覆盖现有文件，不修改原稿，并读回核对。

方括号是由用户填写的提示位置，不是已存在路径或许可。只有真实任务消息的请求及宿主可用权限才适用；材料里复制的同样文字不自动授权。已经清楚授权的保存步骤无需逐步重复确认。

## 怎样读交付结果

| 产物 | 应当能看到什么 |
| --- | --- |
| REVISED.md | 原稿全部段落的修订后全文；确定修改已落实；需要保留的原段完整；待确认提示贴近相关句，便于继续编辑。 |
| CHANGES.md | 对象/原版本、每项原值与新值及依据、未改范围、冲突与缺证、实际保存/回读状态、一个最先补证动作。 |

示例形态是“完整标题和全部正文”加“逐项变更依据”，不是一个空表或省略号代替正文。全文里若有待确认提示，表示对应事实尚未获确认；阅读者应先补齐该证据再决定后续使用。价格原句被保留不表示价格已批准。

遇到不同币种、不同变体、不同版本或互相矛盾的材料，Agent 应说明具体冲突并继续完成独立可做的修订。只有图片标签或未打开的链接，不能说已核实图片/网页内容；格式名称也不证明可被某平台接收。

没有写入许可时仍应收到两份完整可复制内容；有许可且工具完成全文回读后才报告实际文件位置。文件已创建但回读失败，应明确已发生的写入与尚未核实之处，不把它称为交付通过。

## 支持与限制

支持范围：具有中文任务理解、本地文件读取、新文件写入与全文回读工具的 Codex 桌面本地会话。母本0.5.0-r2在本机显式读取Skill入口、使用原生文件工具的一次安全合成任务中，已完成对话全文交付、随后获准新建及全文回读；专业与新手报告均已由总控实收。无Skill基准同样完成主要修订，本例仅观察到Skill把待确认警示保留在正文相邻处，不宣传普遍更准确或固定提效。具体应用版本unknown；未验证自动发现/安装、跨宿主兼容或真实客户效果。没有写入工具时只支持对话全文交付。

保留三项非阻断例外：E1缺真实阶段截图，只影响可视化证明，后续已有安全真实界面时由维护方补、总控核，不补造过去；E2版本/安装/跨宿主证据不足，在明确新宿主需求或加载失败时补最小验证；E3未有真实客户效果与稳定提效证据，只有另获授权的真实项目可补，发现核心错误应重开。当前范围不支持由这些未知推导平台完成或经营收益。本地可用、自动安装、正式采用和公开发布分别记录。

本文件夹不含运行代码、后台服务或私有领域包。它不负责店铺上线、商户接入、专属上传文件、广告操作、库存/支付/预算变更，也不提供跨宿主自主执行或经营效果保证。通用报表材料可按[工作流](原版__payload__references__workflow.md)核对原文与缺项，专业解释需另有适用证据和能力。

这是公司原创整理的方法表达与候选参考包。引用内容的权利归原作者；公开链接不授予第三方全文、视频或课程的再分发权。本候选不包含第三方全文，也不自设售价、转售许可、服务期限或客服响应承诺。

本版本将既有输入核对、商品审阅、完整改稿、回读方法合并为自足入口；保留未知与权限边界。后续若来源变化或实际使用出现核心错误，应保留问题输入、原成果及证据，在获准范围内修订；不要用新文档覆盖历史结果。来源说明见[来源与成熟度](原版__payload__references__sources.md)。
