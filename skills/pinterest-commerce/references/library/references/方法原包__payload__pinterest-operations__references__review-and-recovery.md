# 复盘与恢复

优先修会污染解释的证据：商品/权利/价格→事件语义和身份→窗口口径→经营表现。它是当前公司设计，不是平台优化公式。保留各分支独立HOLD，修好一个字段不解除其余门禁。

|异常|先取什么|可以给什么建议|不能推出什么|
|---|---|---|---|
|商品不显示|来源访问/接收/逐商品诊断及资格|按来源或字段层定位责任|不能无日志宣称遭封禁|
|币种/页面冲突|同SKU同市场真值及转换依据|最小字段建议，保留原值|数字相同不等货币一致|
|事件量大于订单|交易状态、跨渠道身份和去重回执|逐记录分语义错误与重复候选|不能全部当真实购买|
|归因额不同于订单|窗口/触点/快照/退款/金额币种|列可解释差异和剩余未知|不能强行凑平或称增量|
|点击或展示变化|同口径数据和实际变更时点|一次可解释最小变更或继续观察|不能自动加预算/删Pin|

输出一项最小下一动作：对象、负责人角色、所需证据、预期关闭的问题与保持停止的事项。动作只到建议，不替真人派工或承诺操作。恢复须确认原问题和相邻风险，保存输入/方法版本。维护触发见[维护说明](方法原包__payload__pinterest-operations__MAINTENANCE.md)。

## 收到新事实或新目标时

先把新消息与上一轮目标、已交成果和未完成事项对照。已经给出的信息不再重复索取；区分商品事实或证据变化、约束变化、优先顺序调整，以及用户明确改换目标。只调优先级时调整先后顺序；目标确实改变时重新选择路线并说明被替代的任务及理由，不机械保留不再适用的计划。除明确替代或取消外，继续完成原任务仍有效的部分。

找到变化对应的SKU、市场、目的页、素材、原消息或记录时间，再检查依赖它的文案与判断。只替换被新证据实际覆盖的事实；来源撤回使依赖它的结论降级，不让独立证据一并失效。保持原值、来源与版本可回接，不把较新时间自动当成全字段真值。

- 商品价格、数量、用途或规格变化：回查受影响Pin的标题、描述、图中文字、CTA、页面一致性、制作要求，以及相关目录字段与条件广告候选；交付修正后的受影响完整Pin或诊断，保留未变的其他商品成果。
- 原教程或目的页不再可用：停止依赖它的教程承诺或错误跳转；根据仍存在的页面和当前目标重新选择内容承诺，缺页面时给准确页面需求，不编链接。可独立交付的商品文案继续完成。
- 补来目录诊断、事件回执或报表证据：保留完整原消息、对象和时间，只更新它证明的层。摄入修复不推成自然/广告资格，事件接收不推成去重或归因；比较仍按相同对象、日期归集、窗口与口径判断。未涉及的HOLD继续保留。

先给本次受影响成果可直接取用的完整版本，再简述改了什么、保留什么、仍缺什么；不要只交零散替换句让用户自行拼稿，也不默认重抄整套七部分审计。最后给当前目标下一个最优先动作及所需证据。旧首答原样保留；保存新文件仍遵守既有新建与拒覆要求。所有更新限于获授权的离线文稿/分析，不代执行平台、预算或库存动作。
