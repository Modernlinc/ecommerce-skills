# 购物广告：条件不齐也交出可检查的方案

先写业务目的，区别购买、站外访问与Pin近看。使用已观察的界面术语说明意图，不能把它转成广告API/bulk配置。目标S003和PI-0-02为历史观察；O04于2026-10-10复核标准shopping指定段，当前账户与市场资格未证。

## 对象关系与选择

P09证据支持：产品目录中的商品形成product groups；购物路线选择Sales campaign，再在Ad group选择product groups及定向、预算/排期、优化/分发等细节。标准shopping素材围绕组内具体商品。普通board/自然Pin不是已存在的目录或商品组；产品组是目录商品集合，也不是受众。给逻辑名称与预期成员即可，不编平台ID，不套其他平台字段层级。

规划必须交：业务目标与选择理由、campaign/ad group/产品组逻辑图或表、逐组成员/排除原因、素材与逐商品页面、预算与观察条件、责任及开投停止。公司组群选择要根据任务/商品一致性、可售/利润证据；没有利润不称最优分组。官方推荐全商品组不等必须包含有问题商品。当前条件未齐可区分“未来候选成员”和“当前可投集合为空”。

## 创意路径

标准单品静态图规划应明确每个商品的真实图/文案/目标页需求。自然对比Pin可作为内容需求参考，但不能说已被自动转成shopping广告；缺catalog对象和实际素材就只能待验。没有视频、hero或次图证据，不包装成已完成collections路径。关键词/兴趣并非该购物路径必填，不凭这个事实证明无需任何市场/商品约束。

## 花费与复盘

只使用输入明确的预算、总额和风险定义；不得把广告花费上限称为净经营损失上限。未给成本/回收口径，利润或CPA盈亏线unknown。预算/排期记录为供审核的草案，不自动执行；未来授权人须确认平台可用控制与超额风险，不能声称一定硬封顶。

区分交付质量观察和经营效果观察。错商品/价格/权利、事件语义错误、可靠去重/口径未建立时停止相关放行；监测频率由风险和输入设定，不把固定天数叫平台学习完成。到观察日没有足够同窗数据就解释未知，不以零订单自动证明创意失败，不扩量。
