# 输入与输出合同

## 输入先确定用途

自然brief最少需要市场/语言、商品事实、目标页文字或明确缺失、拟素材与权利状态。趋势与账户状态不是离线文字起草的必填前提。目录和广告执行需要的资格不得提前伪装成所有文稿的共同必填。

|资料|需保留的关键内容|缺失处理|
|---|---|---|
|商品/页面|变体ID、外尺寸/数量/用途、商品价及币种、事实日期、逐页面定位|缺哪项就停止相应主张；不扩大性能|
|素材|实际文件是否存在、作者/许可范围、SKU映射、拟承诺|无图只作brief；权利不明素材隔离|
|目录|原始逐变体字段、真值来源、数据时间、更新方式/owner、接收与批准各自回执|原值不覆盖；unknown不是合法上传值|
|广告|业务动作、市场、对象状态、可承受花费/损失的用户定义、观察期|没预算不荐金额；资格缺失保留条件brief和HOLD|
|事件|业务交易状态/时间/订单引用、采集渠道、原标签、关联ID、金额币种、测试/真实标记、同意状态与回执|没有完成交易证据不按名称推断；缺ID不随意补造|
|指标与订单|对象、时间区、起止、过滤器、实时/快照、click/view回溯、订单/退款范围和费用口径|混窗不算率；金额不同币种不相加；退款/成本unknown不填0|

每个输入有来源ID或表行；原始事实、用户假设、公司建议分栏。日期设定与数据生成日不同；.synthetic/.invalid或明确合成标记不能当真实验证。没有数据的其他模式可直接说明不适用，不制造额外题目。

## 导出或摘要的人工整理分支

需要整理导出/摘要时，先读[本地导出合同](方法原包__payload__pinterest-operations__references__export-contract.md)。它定义公司本地标签，真实列映射仍由输入说明证明，不能猜原生列或上传枚举。保留原值、对象字符串/前导零、粒度、起止端点/时区、过滤、快照及每项定位；无列义或范围证据时停止受影响判断。

本分支交付原列→本地字段→证据与状态、逐行计算前条件、可加子集与排除范围、一个优先补证。只列未求值公式，不运行解析器/计算器、不输出最终指标。缺失不当0，零分母N/A；记录数不是展示计数分母，不以一处输入选择解决所有缺项。这不替代下述完整业务链。

## 本轮增量输入与交付

自然路线可补关键词/趋势原材料、地区/语言、时间窗口、用户目的；缺失时仍用商品材料形成拟议词并标draft_hypothesis。交关键词采用/排除理由和逐Pin从意图到具体页面的完整文案，不以空表代替结果。目录路线可补catalog/data source、完整诊断消息、商品ID和时间；缺失层分别unknown，不用上传成功替代分发资格。结果沿用原值、证据、建议、责任和下一回执合同。来源与当前观察范围见round-two-evidence.md。

## 完整链输出合同

完整委托交七部分：业务事实/路线；完整board/Pin文案及构图；逐变体目录原值/建议；有条件广告brief（对象/商品组/创意/预算/观察）；逐事件诊断；指标和订单差异与一项复盘行动；统一责任/证据/停止。

每个结果写依据和局限；区分DRAFT_COMPLETE、HOLD、unknown及NOT_OBSERVED，不合成一个平均通过分数。算术列公式、单位、分母和同口径判断。报告中的阶段完成不是平台批准、QA或许可；本候选可列下一动作建议，不代表给真人发送任务。
