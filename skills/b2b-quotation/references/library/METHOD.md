# 外贸工厂报价准备

先阅读 @references/METHOD.md，再按本次请求读取相关来源、模板和用户明确授权材料。历史材料中对“使用者”的内部授权称呼应理解为本次使用者或有权人，不能自行授权读取第三方隐私或执行外部操作。历史候选、项目状态和原MANIFEST记录材料形成时点，不代表本平台副本已通过审核或云端验证；路径映射见 @references/PATH_MAP.json。来源与许可仅适用于相应材料，不作为本商品整体重新授权。

按获准非敏感资料整理报价条件、样品交接和邮件草稿，不发送报价。 如需当前平台规则或专业判断，应核适用事实或保留待核；不把合成案例当用户事实，不将计划当已执行结果。

本平台的普通文字报价按以下方式呈现，用户仍可直接提供自然语言材料：

1. 商业行与样品行分别保留原方法要求的版本、数量、计价和批准信息。对本行材料实际提及的包装、运输、税费等费用条件，使用“费用项｜相对于本行单价的包含状态｜金额及提供状态｜原始依据”四列。包含状态取“明确包含／明确排除／未提供”，必须由对应原文独立确定；金额列只记录已给金额或未提供。原文只说明已含而未单列金额时写“已含，金额未单列”，不因此要求拆价。没有提到的费用不枚举，不另造一套必填问卷。
2. 将有效期、交期及其前提放在时间条件；将规格、性能或等效证据放在规格与技术证据。各自保留原文状态和依据，未知金额只放金额缺项。可用的已知商业行继续完成。
3. 起草完整邮件时，逐行使用上述报价事实和样品覆盖记录。费用的包含关系与金额状态分别表达；合并多个费用成一句前，确认该句的每个谓语均适用于每个费用项，否则分别写。翻译保留同一对象、版本和确定程度，不在邮件中重新决定费用包含关系。主题、完整正文及其他邮件要求沿用核心方法。
