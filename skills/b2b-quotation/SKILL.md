# 外贸 B2B 报价与样品沟通

## 功能摘要

把询盘中的批量采购、样品和运输问题拆开处理，避免一封邮件混写成已经批准的商业承诺。公开示例根据已给条件组织非绑定报价、样品费用及完整英文回复，明确产能、运费和交期哪些尚未核实，帮助业务人员把补问和审批留给正确责任方，减少未经批准的保证。

适合：工厂询盘与外贸协作学习人员。

## 输入

给定合成询盘、可用报价、样品条件和审批状态。本公开版只使用原创合成材料；真实资料不在本演示范围。

## 输出

非绑定报价表、样品表、完整邮件及补问。交付为可阅读、可检查的文字，不暗示已完成平台执行。

## 演示步骤

1. 读取本项[合成输入](examples/input.md)，先确认任务和已给事实。
2. 分清用户目标、明确事实及未知；缺失事实保持未知。
3. 只在本页公开范围内组织工作稿；不加载付费方法或私有材料。
4. 交出完整请求结果，引用输入中能支持它的事实。
5. 标出限制、待补信息与尚未执行的动作；请求超出范围时停在文字交接。
6. 完成首答后再阅读[示例输出](examples/output.md)比较；参考答案不代表唯一正确表达或独立盲测。

## 限制说明

不自行批准底价、产能、工程可行性或交期，不签约和发邮件；只展示指定合成事项，任意公司和角色下的通用实施未在本演示中验证。

本公开版不是完整付费 Skill，不包含其专业方法、私有references或运行模块。示例不证明商业效果；需要真实账户写入时另行确认权限与实施条件。不要编造缺失事实或把草稿称为已发送、已上线、已投放。
