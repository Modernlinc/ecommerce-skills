# 决策计算与门禁

## 三情景利润

对以下变量分别给基准、保守和压力值：售价、平台费、履约/头程、广告、促销、退货、损耗、汇率、仓储天数、销量、补货延迟。

计算时至少展示：

```text
净收入 = 含税/不含税售价口径调整后收入 - 折扣 - 退款
单位贡献利润 = 净收入 - 单位变动成本
贡献利润率 = 单位贡献利润 / 净收入
库存周转天数 = 平均库存 / 日均销量（明确销量情景）
盈亏平衡销量 = 向上取整(固定投入 / 单位贡献利润)，仅同一范围且单位贡献利润 > 0
```

任何必要字段缺失均保留 `unknown`，不能用 0 代替。净收入非正时不输出常规贡献利润率；净收入为正但贡献为负时应如实显示负利润率。单位贡献非正时不输出有限回本销量。分母包含哪些成本须与固定投入互斥。

每笔成本或退款保留唯一 ID、口径和落点：已从收入冲减的折扣/退款不再作为同额费用；退货处理费、无法回收的货损及回收价值另列，不把全部商品价值再扣一次。采购价已含包装时不得重复加包装。区分广告前贡献与扣除广告后的贡献；广告只扣一次。仅已知成本后的余额不称完整利润，固定设计/测试费不重复摊入单位成本后又作回本分子。

除利润率外，同时比较总贡献利润、库存周转、回款周期和首批现金占用；高毛利低周转不自动优于中毛利快周转。

## 现金时间轴

利润为正不代表本周期有现金。按支付/到账事件列出备料/订金、尾款、头程、到仓、销售、退款窗口、平台结算与预留释放、供应商账期和运营支出；统一币种、日期和情景。周/月汇总必须保留期内顺序，否则保守先付后收或标记峰值 `unknown`。

```text
B_t = B_(t-1) + I_t + F_t - O_t
现金余量_t = B_t - H_t
现金缺口_t = max(0, H_t - B_t)
最差现金缺口 = max(各事件现金缺口)，同时报告首次触发日
```

B_0 为已分配本方案、未受限且未重复承诺的初始资金，只计一次；I_t 仅为银行净到账或有明确到账日/金额依据的预测，实际与预测分栏；F_t 仅已落实且获准使用的新增资金，另列 F=0 基线；O_t 是尚未在净回款扣除的到期现金支出。H_t 是最低保留现金阈值，不作费用或重复扣款。没有实际注资不得把“补足缺口”加回后期；每期缺口不能相加冒充资金需要。

本轮只支持净回款路径，不做完整毛额平台余额适配。净款已扣的费用、退款、预留不再扣；预留释放也不在已含它的打款之外再加一次。毛/净额、费用/退款落点或预留释放依据不明时，标 `unknown / 待对账`，不推定可用净款或安全余量。利润记录与现金记录是不同口径，同一现金事件在现金轴中只出现一次。

首批已知支出小计、事件轴的最大累计资金占用、最大可承受损失分别报告；预留是到账限制、缓冲是保留阈值，不能作为额外永久成本相加。没有现金时点、销售/回收情景或退货/尾货处置依据，就不能从支出小计推定峰值现金或最坏损失。生产/运输/结算存在重叠与分批时，以事件轴为准，不套相加天数公式。

反例：B_0=1000、H=0、无回款和新增融资，两期各付800，余额依次200、-600，第二期缺口600。这是经总控审定的计量合同与代数推导，不冒称课程或 Amazon 官方给定公式。

## 硬门禁顺序

1. 法律/平台/安全/IP 是否允许。
2. 需求是否跨信号且可解释。
3. 缺口是否真实、可解决且可证明。
4. 单位经济和现金流是否在压力情景可承受。
5. 供应链/质检/履约是否可执行。
6. 最小验证是否可逆且有停止线。

任何硬门禁失败，不用加权总分覆盖。

合规阻断后可给内部证据缺口表和已知输入的受限算术，不能给采购/样品/小批准入；主状态与其他失败并列，未知不等于违法。状态解释见 Skill“决策输出”。

## 候选取舍与下一证据

这是已有候选的离线研究组织方法，不是销量预测或采购评分模型。先用当前目标、用户任务和必须满足的约束确定比较对象；已有替代方案能完成任务时把它作为对照，不能假定必须开发新品。只比较会改变这次选择的差异，不因表中有字段就全填。

对每个关键差异说明：它怎样影响任务完成、整包购买负担、首批资金/现金时点或交期；证据覆盖什么对象/条件；哪项反证会改变解释。计量统一不代表任务或性能等价，低单位价也可能伴随不需要的包数和更高初始承诺。价格/数量、任务/性能、完整经济性分别判断，不把未知合成一个总分。

在已知目标和证据范围内给一个有理由的优先研究方向与必要备选，写清得到什么、放弃什么；关键差异未证时给条件分支，例如“若这个任务/成本条件成立则先研究甲，否则转乙”，而不是无条件排名。若证据支持不增加新品或现有替代已足够，可建议不进入该新增方向。合规等硬阻断保持原主状态，这里的研究优先级不等于采购/样品/小批准入；不足以区分时说明真正缺的决定性证据，不强造赢家。

下一证据优先回答能改变保留/暂缓/放弃选择的问题。先处理安全硬阻断所需的内部证据，再比较其他问题的决策影响、可获取性和可逆成本；一个困难外部来源只暂停依赖它的动作，已知算术、任务对照和其他内部材料核对继续。不要为了最容易拿到的资料忽略高影响反证，也不要求填满所有证据。

用既有“下一步验证”栏交具体安排：要区分哪两个解释、针对哪个版本/任务、先用哪份已有材料和怎样检查、什么可观察结果支持各分支、内部负责人/顺序、何时停止或另需许可。没有性能/接受度依据不编合格阈值；若暂不能确定判据，先设计能确定判据所需的记录核对。正文先给条件取舍与安排，再附支撑对照；未知只限制依赖它的结论。

## 新条件下的接续

先识别本轮改变的是证据、约束、优先级还是目标本身；已经明确的新目标可以改变原计划，只有含糊且影响取舍时才问。沿“来源/版本→任务与比较→成本现金/时间→结论→验证安排”检查真正受影响的部分。撤回或冲突的证据只撤销依赖它的判断，不抹掉其他仍成立的记录；报价/规格变化继续按供货同对象方法处理。

更新所有受影响的对照、金额/时序、优先方向及下一验证，并说明重要的未变项为何仍成立。优先级改变时保留原目标和未完成项；目标被明确替换时，把旧计划标为被替代而非完成，不机械继续旧目标。新资料只解除它实际补齐的缺口，不自动解除其他门禁。

本次交付应独立可用：给更新后的条件结论、相关对照和具体下一步，简述改变与继承条件；不要让用户拼接两轮才能知道现在做什么，也不在中间回合重复整份审计档案。只需未变证据定位时用已有文件名/章节回接，不改保存的历史首答。

## 产品开发与验证升级阶梯

这是一项按风险选择下一证据的公司研究设计，不是来源已证明有效的固定阶梯。按 [主张准入表](claim-admission-and-maturity.md) 使用：

1. 先从已授权的有限原始记录提出任务、根因与替代解释；没有故障/行为证据不把原因写成事实。
2. 把影响下一判断的缺口写成证据清单：对应记录、最低证据、内部负责人及停止点；允许不采样、不采购的内部整理。
3. 门禁与动作授权满足后，才选专业可行性、样品/原型、任务测试或其他风险相称步骤；每步说明为何能回答问题。
4. 样本与判据按任务说明依据，不设通用件数、次数或自动晋级阈值。一次售罄、正回款、好评或内容爆发均不证明重复成交和经营可行。
5. 结果只支持已测条件；仍缺需求、完整成本、安全或供应能力证据时不推进开模、库存或功能定稿。
## 证据冲突

- 官方当前事实覆盖课程中的平台事实。
- 效果冲突按市场、品类、时间、样本、利益关系和执行条件拆分。
- 无法裁决时输出条件分支或 `unknown`。
- 第三方销量/需求估算不得与实际订单混为同一精度。

## 容量、流量入口与竞争时钟

先判断容量估计是否可行：可比对象的市场、时间、价格、履约、可见性及产品差异是否有证据，估计方法是否有可验证校准和误差边界。新解法的任务/替代/分群只是研究入口，不能自动推出市场区间。缺少上述依据就写容量 unknown，列下一原始证据，不给数字、不据此 advance。头部销量、BSR 或固定 1.x 衰减不是预测模型。

每个候选记录首个流量入口假设、支持与反证及最低下一证据；没有真实触达证据时入口和 why_win 都不是已验证胜因。低 CPC、FBM 出单、跨平台热卖、弱搜索结果、采购端成交与新品密度均为候选信号；它们需要与目标市场、任务、时间窗和单位经济交叉验证。

用同一决策起点、日历和单位比较“预计可售日期区间”与有证据的季节/竞争窗口终点。决策、打样/认证、生产、头程、入仓/上架及学习期按依赖关系排程；有并行证据取关键路径，无并行证据可保守串行，缺时长则区间或 `unknown`。新品进入/复制速度、价格与 CPC 变化分别记录观察窗、单位和压力影响，不能与天数相加，也不能无依据换算成剩余天数。

例如同一起点下生产21天加运输25天的串行下限为46天，已超过6周即42天的窗口，且还没计入其他步骤；这个比较只说明时机风险，不能推断销量或利润必然下降。

当同质化竞争可能在到货前使压力情景失效，结论为 `hold_for_more_evidence` 或 `reject`。

## VOC 研究质量

1. 先写决策问题，再按购买前、使用后、退货/服务或第一方实验选择来源。
2. 保存市场、时间窗、样本、排除/去重规则和原始记录 ID。
3. 在有授权的有限样本内，逐条记录原始 ID、上下文、解释者、假设、相反解释与下一证据。拒用不可回接的条目；不要把独立重复故障随意去重。
4. 撤出默认 AI 批量标注、置信阈值分流和自动升级；标签本/校准/抽检方案只作可选 method_hypothesis，未证明电商效度。人工核对、模型一致率或填完字段不能证明真值、根因或规格。
5. 高频、情绪或图表位置只生成假设；回看原文、替代解释、少数严重事件和来源偏差。
6. 不推断敏感/不可证明画像；记录访问权、用途、最小化和保留期限。
7. 每项解释连接内部责任人、最低下一证据与停止条件；没有原始故障/行为、性能及接受度证据时根因和规格保持 unknown/假设。

## 决策成熟度

以下是任务状态标签，不是完成表格后的自动升级规则，也不表示本 Skill 已获公司终验。每级仍按主张准入、硬门禁和动作授权判断；证据存在不等于证据足够，L1—L4 不证明经营效果。

- `L0 idea`：只有方向/榜单/AI 建议。
- `L1 screened`：完成范围、初筛和硬风险扫描。
- `L2 evidenced`：需求、竞争、VOC、经济和供应链有可回接证据。
- `L3 sample_ready`：合规预审、供应商报价和样品计划完整。
- `L4 validation_ready`：小批量测试预算、指标、停止线获授权。
- `L5 validated_for_defined_scope`：只在已声明市场、平台、价格和周期下得到验证；不等于可无限扩量。
