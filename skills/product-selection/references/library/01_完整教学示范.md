# 不是最便宜就先选：桌面理线的两次取舍

这是既有合成案例的教学整理，不是真实商品推荐，也不是 2026-10-19 新增独立测试。最后的 MOQ 变式是本次明确假设的算术演示。全部金额均为英镑，无真实报价核验、市场采集或采购。

## 1. 用户给了什么

目标：面向英国居家办公场景，先研究怎样让桌边充电线头不掉到地上，同时尽量控制首批资金承诺。只在两个已有方向间比较。

- A「DeskClip / A-v1」：每袋4个可重复开合线夹，£1.20/袋，MOQ 300袋，含普通袋装、不含运输税费。材料称夹在桌边、不用胶；文字转述的设计图只涉及18–25 mm平直桌沿，未提供曲边、线径或反复开合记录。
- B「CableLoop / B-v1」：每袋12条理线带，£0.72/袋，MOQ 100袋，同样含普通袋装、不含运输税费。已述用途为捆拢线束，未证能将单个线头留在桌边。
- 现有替代是普通长尾夹，只有同事描述，没有性能或接受度记录。
- 货物采购额上限£500，另留£200未分配储备。没有运输报价、售价、完整成本、付款/回款时点或总损失上限。
- 三句模拟原话为：“我只想充电线别掉到地上”“桌沿是圆弧的，不知道夹不夹得住”“一整包买很多个可能用不完”。三句话不代表三位独立用户；发生时间、人数和代表性未知。
- 没有安全/IP/合规、真实需求和竞品表现证据。只做文字研究，不联网、外联、买样或采购。

## 2. 首次成果：优先研究 A 的任务适配，不承诺买 A

先研究 A 的桌边固定假设，B 保留为条件备选，普通长尾夹作为对照。A 的结构方向较贴近“留住线头”；B 的已述捆线用途不同，便宜不能补上任务缺口。当前投入为内部整理时间，新增外部支出£0。

| 可比项 | A-v1 | B-v1 | 怎样用于判断 |
| --- | ---: | ---: | --- |
| 包装数量 | 4个/袋 | 12条/袋 | 来自明确字段，不猜标题数字 |
| 袋价 | £1.20 | £0.72 | 都只含普通袋装 |
| 件均采购价 | £1.20÷4＝£0.30/个 | £0.72÷12＝£0.06/条 | 是不同物件的计量，不能当成完成同一任务的成本 |
| MOQ | 300袋 | 100袋 | 要看整批承诺，不只看单件价 |
| MOQ货款 | £1.20×300＝£360 | £0.72×100＝£72 | A多承诺£288，所以先澄清任务优势是否成立 |
| 距£500货款上限 | £140 | £428 | 不是完整资金安全余量 |
| 批次物件数 | 1,200个 | 1,200条 | 数量相同不代表可服务同样多的用户或桌面 |
| 核心任务关系 | 桌边固定方向相关，但性能未证 | 能捆线，单个线头固定未证 | A为条件优先，B尚非同任务等价方案 |

£200储备不自动变成采购额度，不把货款上限改成£700。袋装已含，不再另扣；运费、税费等缺项不按0。£360和£72只是货款，不是完整利润、峰值现金或最大损失，这三项仍未知。这里没有足够信息编造基准/保守/压力利润。

三句原话能做的是提问，不是定规格：

| 原话位置 | 当前研究解释 | 不能直接推出什么 |
| --- | --- | --- |
| 第1句：线头别掉 | 目标是线头易取，不是所有理线问题 | 市场规模、购买意愿、A已经有效 |
| 第2句：圆弧桌沿 | 平直桌沿图示未覆盖这一情境 | 所有曲边都失败，或应设计某个确定尺寸 |
| 第3句：一包用不完 | 需要查所指包装与实际用量 | 这句针对A或B，或必须改成单个装 |

产品定义线索可以写成：“在桌边使用线材时，让闲置线头停在容易取用的位置；需核桌沿形态、线径、取用和反复开合表现。”不能补写未经证实的材料、夹力、耐久次数或合格率。普通长尾夹若已经能完成同一任务且可接受，就未必需要新品；本例尚未证明这一点。

## 3. 具体下一步，以及何时改判

当前所有可用材料就是上述文字，不能声称另有报告可查。先由研究负责人完成现有材料的缺证索引；后续资料提供者与专业审阅负责人待指定。

| 内部顺序 | 本轮已能写清的结果 | 下一份证据要回答什么 | 结果怎样改变判断 |
| --- | --- | --- | --- |
| 先列硬风险缺项 | A-v1、B-v1及长尾夹均缺对象适用的安全/材料/权利依据 | 现有报告、用途和版本是否对应，适用审阅是否充分 | 未补足时业务推进仍阻断；未知不等于违法，内部比较可以继续 |
| 再核同任务 | A只有桌边固定设计方向，B只有捆线描述，长尾夹只有转述 | 对应版本的结构说明与任务记录：线头怎样固定、何时滑落、怎样取用 | A不适配则暂停；B若证实同任务且条件可接受则重排；替代已足够可不新增商品 |
| 再看适配与购买负担 | 曲边、线径及每次需用数量未证 | 具体桌沿/线材、实际用量与包装选择记录 | 仅修改受影响的适配或包装假设，不直接改规格或沿用旧价算改款 |
| 再补完整资源约束 | 已算MOQ货款，储备未动用 | 同版报价含项、付款/履约时点、完整成本及损失上限 | 压力条件超出约束则暂停对应方案；不靠预计销量或复购补缺项 |

最先可交付的是这张内部缺证索引，不是供应商联络或样品测试。两款业务推进状态均为“合规/安全/IP证据阻断”（`blocked_compliance`）；同时保留需求、性能和完整成本缺口，不给采购晋级。支出与采购数量均为0。收到一份性能记录，只能解除它覆盖的性能问题，不能顺便宣布需求、安全或利润成立。

## 4. 用户改变目标后，交一份当前可用结果

用户接着说：“先不做线头别掉，改为把桌下四条散开的线捆整齐。预算和报价不变，旧方向留着，不采购。”

此时优先研究 B，A 随原方向暂停。理由是 B 的已述捆线用途更贴近新任务，且MOQ货款更低；这不是出现了新的实测证据，也不是原A判断被证伪。

| 当前决定 | 更新后的理由与保留条件 |
| --- | --- |
| B先研究 | 对应四线捆拢任务；£0.72×100＝£72货款，距£500上限£428。线径/束径、长度、闭合方式、滑脱/损伤及拆装表现仍未证 |
| A和旧方向暂停 | £360货款、£140货款余量仍成立，但平直桌沿设计信息不证明能做桌下捆线；旧曲边与开合问题未完成 |
| 不强造第二候选 | 长尾夹原来只有桌边固定描述，不能自动成为新任务替代。若B不适配且无已证替代，可暂不新增商品 |
| 原证据按用途保留 | 第1、2句只服务旧线头/桌沿问题；第3句仍只是包装负担线索，未证明B的12条装过量 |

£200仍是未分配储备。袋装不重扣、运输税费等仍未知；完整利润、现金峰值与总损失仍不能判断。4条线不等于4条理线带，也不证明1条就够，不能把一袋折算成可服务桌面数。

当前内部下一步转向B-v1：先保留安全/IP/合规缺证，再整理四线的线径/束径、整理区段、结构与任务表现所需记录，然后核实际用量、包装选择和完整成本。若B无法适配或需超出资源的改造，暂停该方向，不自动回到A。没有新增材料时停在这个问题清单，不虚构阈值或发起实物实验。支出£0、不采购；旧方向的剩余问题仍可在未来接续。

## 5. 单价更低，但 MOQ 更高：一项教学变式

单独假设新报价 B-Q2 仍为£0.72/袋、12条/袋，但MOQ变为1,000袋；其余给定限制不变。这不是原实际跟进，也不是收到的真实报价。

件均价仍是£0.06，但MOQ货款变成£720，比£500货款上限高£220。£200储备没有被授权转用，不能用它抹掉约束。B仍贴近“四线捆拢”的任务，却不能据此认为当前报价可进入采购。保留B的任务研究，暂缓这份报价对应的资金承诺；下一证据是对应版本的数量/报价条件及完整成本，而不是立即换供应商或付款。也不能因B资金不合适就选没有同任务性能证据的A。

这说明必须分别判断任务是否相关、单位口径是否可比、整批资源是否容纳。它是既有方法的教学应用，不是通用最优采购公式；本轮尚未独立验证模型在这个变式中的实际行为。
