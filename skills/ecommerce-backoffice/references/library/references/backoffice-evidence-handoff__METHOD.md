# 业务摘要核对与异常交接

先读[材料规则](backoffice-evidence-handoff__references__material-review.md)的读前准入，再决定是否打开业务材料。根据已给的具体对象/字段范围、来源性质、提供权和用途授权判断；已有信息够用就继续，缺失只问关键项，不能先看正文判敏或扫盘找材料。真实客户/订单、合同、银行支付、发票税报、保密材料及其脱敏件仍在对象级确认门外；路径可读、内部角色或“摘要”标签不自证许可。

本版接受本版声明范围内的新非敏感摘要，不限定旧例编号/数值。从普通目标选需要的模块，先给当前可用结论、首要核查及理由，再交原值对照、有限算术、异常影响、具体补件和拟岗位。无需完整JSON或四个空表；缺上游原件不阻断安全摘要内有据的比较。

为每个结论保留摘要来源/条目定位、交易与行项、币种单位、版本/期间及未知。摘要只证明该来源如此陈述，不能当已核原件、到账、签收、批准或法律事实。费用同名同额不自证同项；已明确同项且含在净额中不得再扣，缺覆盖不猜合并。

按材料规则处理明确的补充、字段替代、撤证及目标变化：只更新相关依赖和问题，保留旧值追溯及无关事实。日期较晚不自动有效；申请、批准、执行、结算、到账和岗位接收分开。未知、未提供、否定与来源给定零不可互换。

交付本轮完整可审阅稿、变化理由、仍有效/未决事项和下一步。岗位只是建议，不代表已派发/接收/批准。不作会计、税务、合同效力或完整利润结论，不执行付款退款、库存物流、签署申报、客户联系或发布；涉及受限材料停在读取前另请使用者确认，许可不替代能力边界。

需要结构化记录时可用[原记录模板](backoffice-evidence-handoff__assets__output-template.json)，未涉及模块不强填；需要来源成熟度时读[来源与边界](backoffice-evidence-handoff__references__sources-and-boundaries.md)。[中文入口](00_开始使用.md)与[教学导读](01_完整教学示范.md)均在本包内；教学旧例不是当前任务输入。
