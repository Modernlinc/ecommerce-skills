# 业务报告合同

标任务结果、输入版本/范围和状态。按用户实际选择的路径交实质正文，不以空表、JSON或PASS替代业务内容。

交付先给本次可直接使用的完整成果和关键取舍理由，再简述依据、限制和一个下一步；以下路径按需采用，不要求每个中间回合重复完整审计档案。条件变化按[渠道表第3.3节](CHANNEL_PLAN.md#33-新条件下继续交付按需)接续：要整套当前稿就交齐；局部改稿交完整新稿并回接未变稿的具名版本，写清实际影响，不能只给散落修改句让用户拼装，也不把旧接收状态用于新版本。

1. 商品/Offer：场景、可证选择理由、替代条件、交易限制和进入条件。
2. 经营：需要时列情景变化/算式/单位/缺项、逐时点现金、充分与不足范围。
3. 创意：需要时交完整brief、镜头动作/依据/验收、各平台消费者文字及页面对应。
4. 许可：需要时列对象版本、用途变化、期限/撤回影响及责任位置。
5. 描述复盘：列各报表口径、可算描述结果和不可比原因，不把条件子集推为总体效果。
6. 实验准备：只有本次需要时才交以下填实内容，按[方法](../references/experiment-and-review.md)逐步整理，缺项写证据与用途，不机械堆空格。

|准备产物|正文必须呈现|
|---|---|
|T1覆盖|目标总体、已记录分配、观察/购买/签收子集各自能回答什么；已知范围与未知分母/回接，分配有效性证据另列。涉及曝光比较时填实际选择到曝光的已知关系、先后、单位及未知/不可取得处；反事实曝光单列代理依据与假设，不以比例近似宣布有效|
|T2结局|已确认主结局或具名候选、辅助项；总体/计量单位/市场/时间/退款成本口径及取数要求。涉及全体分配者与曝光条件对象时，分别列目标、选择/反事实依据及结果和成本分母，指出能回答与不能替代的问题，不签ROI偏差方向或精度优势|
|T3状态|每个相关结局的值状态×成熟状态、覆盖期间/截止/证据、未知或冲突；未成熟已核零仅为快照|
|准备判断|拟比较内容、可描述与不可推断范围、责任位置和按证据触发的停止点；表填满不意味着因果合同成立|

资料不足仍交已有完整业务内容、具体覆盖/结局候选/状态缺口；不得全部替换成HOLD。保留原分配但结果不可见，不补出结果；未购买不等于经营金额零。缺有效分配、干扰、缺失机制、成熟或不确定性依据时，明确停止哪种数值或执行。

最后只选一个优先下一证据：哪一角色核哪份最小汇总、能改变什么、拿不到如何保留已有产物。关键结论紧邻输入ID/来源ID。写清预测、候选、未运行与未观察；不声称独立行为验证、实际账号/发布或实验已完成。
