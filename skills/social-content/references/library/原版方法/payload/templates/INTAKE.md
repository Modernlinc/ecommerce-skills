# 按本次任务逐步整理输入

输入ID/版本/日期；真实或合成；本次目标、已有资料与授权动作。先用已有合法最小汇总，不让用户从空白一次填完整三表。

先确认本次要做商品经营、创意、许可、描述复盘或实验准备中的哪项；已有答案直接映射。每次只问影响当前判断的关键缺项，并说清哪份证据能解决什么，拿不到仍交已知部分。

- 商品/Offer：场景、购买障碍、规格/限制/依据、已知替代、价格/履约/退货/页面状态。
- 创意：平台/语言/市场、自然或付费、商品事实/禁用主张、文案/镜头/CTA。
- 经营：币种、单位/期间、收入已扣项/追加成本/未知、情景参数依据；现金期初/时序/到账状态/保留线。
- 许可：素材ID/版本、证明范围、地域/平台/自然付费/改编、期限/撤回及影响。
- 描述复盘：逐报表期间、分母、去重、归因、退款成熟状态与已知分子分母；不要求提供真实客户身份。

若选择实验准备，按[三表方法](../references/experiment-and-review.md)逐步填已知格：
1. T1：先写想回答的总体和已记录分配/观察对象；仅在需要判断覆盖时补组数、子集、排除时点与合法回接。涉及广告曝光比较时，按已有最小汇总逐步核资格/分配、竞价入选、内容位置、实际及本会曝光的关系、先后与证据可得性；不知道或取不到就明示，不索取真实ID。分组记录或曝光比例接近不等于有效随机/无干扰；unknown不反推。
2. T2：先明确业务问题与主结局是否已由负责人确认；再补适用总体、计量单位、时间/市场/币种、成本与退款口径、辅助指标及取数来源。涉及曝光比较时，另核全体分配者与实际/本会曝光对象各自的目标、选择/推断依据及结果和成本分母，不因可得数据改变目标。未定时交候选及要求，不代选或分摊，不判ROI偏差方向。
3. T3：对当前主结局分别填值状态和成熟状态，连同已覆盖期间、截止、证据及缺失原因。未成熟时的已核零只是截止快照；无事件或无日志不自动是零。

每项回接证据ID，未知写具体缺项和用途；不预填示例金额、补零、等待天数或MAR假设。纯创意无需三表或财务全量。
原有计算接口见[商品经营](../references/offer-economics-cash.md)，历史格式示例见[经营输入](../examples/operating-review/INPUT.md)；示例继承未重跑，未证明本版三表路径。
