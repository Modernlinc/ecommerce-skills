# Foldbox S：先量柜子，再决定购买

SOCIAL-S1-CASE01 / 输出v1.0 / 2026-09-05。当前结论：**创作准备草案已完成，所有真实使用保持停止。** 输入与许可均为虚构，尚无实拍或真实效果。该任务包可交制作人理解要拍什么、平台负责人确认怎样使用；不能当可发布成片或广告创建结果。

## 1. 商品判断与主要问题

购买障碍是“放不放得下”，先给尺寸判断所需信息，再谈收纳效果。主张只用I01–I03：展开/折叠尺寸与擦拭限制。I04的三条虚构访谈只决定本样例选题，不证明真实市场需求。

I02与I01相减，理想矩形柜内名义余量每向2 cm；按商品各向最大+0.5 cm，内腔余量仍每向1.5 cm，柜口宽/高名义各比对应盒体尺寸多1 cm、最大公差时多0.5 cm。这里只是正向对齐的尺寸算式；柜口朝向、铰链、操作余量、柜体测量公差和真实试放未验，不能推成“保证放得下”。不在消费者广告展示“适合所有柜子”。[I01/I02]

**创意的核心承诺**：先让用户知道该量什么、在哪里核产品尺寸，帮助自己决定是否合适。是否减少退货是待实验问题。[I04/E04]

## 2. 给制作人的创意brief

- 受众情景：正整理家中柜子、担心买错尺寸的人；不猜年龄、收入或敏感画像。
- 单一信息：比较柜内、柜口与展开尺寸；折叠后高度另列，不能以折叠尺寸暗示装物容量。
- 表达基调：清晰的量尺演示，避免夸张前后变化、假顾客、抢购或收益语言。
- 核心异议：柜口是否比柜内窄；铰链会否阻挡；展开与折叠尺寸不同；不能依据单个样柜保证用户家中适配。
- CTA：英文“Check the dimensions and care details before you buy.” 对应I05尺寸/护理信息；没有真实网址，最终动作路径待平台负责人确认。
- 优先使用A01的原创拍摄计划。A02/A03/A04均不进入本次拍摄剪辑。

## 6. 一条实验准备草案：柜口测量提示是否减少尺寸误购

状态：DESIGN_ONLY / HOLD。这是待平台及测量负责人审阅的假设，没有执行。两平台上述不同表现形式不互作A/B，TikTok本版只另备表达；拟实验限Meta同一条路径内部，避免把平台差异当单变量。

- **假设**：在其余商品信息、价格、目标页和投放条件相同的情况下，给量柜镜头增加柜口/内腔测量提示，可能减少因尺寸不适退货。
- **A/B唯一拟变化**：相同P02原片，A无柜口/内腔提示叠字，B加提示；两组均保留相同I01产品尺寸、P01/P04/P05/P06、旁白、CTA与页面。若实现时另改价格、开头镜头、时长或目标页，必须记录组合变化，不能报单一提示效果。
- **主要业务指标**：同一分配组内，已签收且观察窗口成熟订单中的“尺寸不适”退货数／该组全部窗口成熟签收订单。退货原因只接受有依据的汇总分类；无合法分组或成熟度时不能算。CTR与尺寸页访问只是诊断指标，不取代主要指标。
- **分配与对照**：拟用平台负责人能够证实的稳定分组和互斥暴露设计；随机/互斥实现、可比流量与事件回读均unknown。未确认前不称随机实验；若仅自然前后对比，只报描述性关联。只请求合法匿名汇总，不索取个人订单身份。
- **读数窗口**：I05仅给申请退货30日的草案，退款处理滞后unknown，因此实际成熟窗口unknown；不能把第31天自动当成熟。经营负责人须给真实政策、签收cohort、滞后上限与缺失处理。最大等待、样本量、最小有意义变化均待该方案批准，不虚构统计阈值。
- **财务与停止**：当前新增真实支出上限0；未来损失上限unknown，成本/现金缺口未补，不可开跑。许可/商品事实不符、组间污染、无法定义分母/成熟窗口、监测失效或需要真实账户动作时停止相应执行，保留已有草案。
- **读数条件**：只有受控设计、成熟口径、样本不确定性与成本均能解释，才交负责人决定是否继续；没有数据就写unknown，不能输出实验赢了。任何公开发布、付费创建/暂停/回滚都需要具体授权，当前只是拟停用方案。
