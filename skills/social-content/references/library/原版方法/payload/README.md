## 从这里开始

把本目录提供给能读UTF-8 Markdown/CSV/JSON的Agent，从[入口](METHOD.md)选择本次任务。若渠道已给定，打开[交接表](templates/CHANNEL_PLAN.md)，提供已有商品事实、普通目标（已有渠道目的也一并给出）、素材用途和页面材料；按表内说明交共用事实、逐渠道完整文稿/制作计划、专业待核项和一个优先证据。后续条件变化时给新材料或新委托，由第3.3节更新完整当前成果。缺价格、素材或平台条件时仅停止受影响部分，不把整份草稿替换为HOLD。

其他商品经营/描述复盘任务使用[通用输入](templates/INTAKE.md)的相关字段。纯内容交接不需要Python或平台包；计算分支才需要现有Python 3及标准库，接口与限制见[商品经营](references/offer-economics-cash.md)。无需安装器，不自动联网或连接账号。没有必要的当前专业证据时，不作平台设置、资格、政策或因果结论。
