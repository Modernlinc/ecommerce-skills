# 缺项与停止

|缺项或冲突|继续交付|停止/下一证据|
|---|---|---|
|经营金额全缺|商品事实、完整文案/镜头与权利问题|经济可行性/现金/实验执行unknown；不用标价代净额|
|某成本unknown|明示已知成本范围余量|完整声明范围unknown，核具体成本与是否已含|
|成本重叠或币种混合|指出冲突位置，其他无关创意可继续|拒绝受影响算式，不自行决定汇率/改名|
|现金事件逆序或同刻先后不明|保留输入和冲突|先核实际顺序；未知金额后余额未知|
|许可到期/用途越界|影响表与自有替代准备|不外用、不自动通知或下架|
|无媒体/真实体验|镜头/文字草案|不得验实测、声画、体验或人物许可|
|平台窗口不一致|各报告并列与描述性指标|不相加归因、不排名增量|
|实验因果依据缺失|业务问题与具名待核项|设计HOLD，不编样本数或因果结果|

unknown不等于0、失败或已亏损。HOLD只约束相应执行；报告仍写可完成的实质部分，并选一个当前优先动作。若用户改变范围先保存原输入身份，不能改原输入来凑结论。
