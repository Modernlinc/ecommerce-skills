# 两平台共用草案与专业交接

本包自行完成商品事实、完整Meta/TikTok文字、镜头、页面一致性和许可拟用途表；这些产物不需要私有文件或平台Skill。专业模块正文未随包提供，也未在本轮读取。

交平台负责人：目标市场/语言、品牌身份、自然或付费用途、商品事实ID、素材版本与权利范围、消费者文字、镜头顺序、CTA与目标页证据、不得采用的主张、待核项。拿不到专业模块仍输出这份完整交接，不声称创建成功。

需要返回：合法具版本来源及核验日期、实际可用展示位置/格式、CTA访问方式、账户与目标页资格、适用披露/规则、若涉及测量则事件定义/去重/归因窗口/成熟口径。Meta对象层级、TikTok Shop/LIVE/Spark/GMV Max等专业设置不从模型记忆补。法域/版本不符则重新核验相应分支。

仅当本次任务要求真实平台设置/政策判断时，这些证据成为该专业分支必需项；不会把缺它说成所有创意无用，也不会把本包说成已能代投。若用户期待的共用任务仍需要隐藏模块，标PACKAGE_BLOCKED_DEPENDENCY并报告具体断点。
