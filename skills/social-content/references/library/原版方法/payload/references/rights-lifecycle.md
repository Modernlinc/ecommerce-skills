# 素材许可生命周期的准备性分析

只据用户给定许可材料判断拟用途是否得到支持；摘要不是已核原件，不能签法律合规或实际媒体验收。

为每素材建最小行：对象ID/版本、作者或授权方、证明范围、地域、平台、自然/付费、改编、起止/撤回条件、拟用途、受影响产物及负责人。比较必须逐维匹配；TikTok自然授权不延伸到Meta/付费，剪辑也可能超改编范围。授权方身份/原件/媒体不齐时标条件支持或unknown，不把署名当许可。

将当前用途、拟改变用途和拟使用日期分别判断。过期或撤回时输出影响表：哪个素材版本、哪些草案/计划、从何时不能再依该许可、替代准备和谁核对。撤回若只是假设应明确条件，不能说已经撤回；截止日未提供时区时边界时刻待核。没有授权不得自动联系、续权、下架、删除或监控。

给一条可继续的替代路线，如自有原创拍摄且事实可证；不要通过AI重画、改人物或变声规避未知权利。无媒体的情况不能审实际配乐/人物/披露声画，即使许可摘要支持拟用途也须单列。商业关系与主张证据分别保存，真实体验不能编造。

此路径的完整结果是一张有实际对象与日期的影响表和准备动作，不是统一写HOLD。需要当日法律结论时停法律分支，交具市场/问题/日期的核验需求。
